# 07. 규정 체크리스트

법률 자문이 아니라 공개된 규정과 보도를 정리한 것입니다. 유료 멤버십, 협찬, 제휴처럼 돈이 오가는 일을 시작하기 전에는 변호사나 세무사에게 확인합니다. ✅ = 검색으로 확인, ⚠️ = 보도·2차 자료 기준

## A. 업로드 전 매번 확인 (복사해서 06_검수.md에 붙여 쓰기)
```
[건강 표현]
- [ ] "낫는다·완치·치료된다·거의 모두" 같은 단정 표현 없음
- [ ] 관찰 연구는 "관련·경향"으로 표현
- [ ] 위험 주제(심장, 약물, 임신, 만성질환)에 "담당 의사와 상의" 문장
- [ ] 특정 식품을 질병 예방·치료제처럼 말하지 않음
[사칭·AI]
- [ ] 오래 박사가 의사·약사·자격자처럼 말하거나 보이지 않음 (흰 가운, 청진기, 자격 표기 없음)
- [ ] 사실적인 AI 음성이면 업로드 시 '변경된 콘텐츠: 예' 표시
- [ ] 설명란에 "AI 음성으로 제작, 대본은 직접 작성·검수" 문구
- [ ] 실존 인물의 얼굴·목소리를 흉내 내지 않음
[수익화 정책]
- [ ] 대본이 이전 영상의 단어만 바꾼 템플릿이 아님 (구성·사례·해석이 새로 쓰임)
- [ ] 불안·공포를 과도하게 자극하는 제목이나 장면 없음
[상표·저작권]
- [ ] 화면·썸네일에 실존 브랜드 로고·제품명 없음
- [ ] 다른 채널의 대본·썸네일을 그대로 베끼지 않음
[경제]
- [ ] 특정 종목·코인 매수 권유 없음
- [ ] 금융상품(보험·펀드) 협찬 시 별도 확인 완료
[광고 표시]
- [ ] 대가를 받은 영상이면 제목 또는 영상 시작에 "광고/유료광고 포함" 표시 + YouTube 유료 프로모션 체크
- [ ] 제휴 링크가 있으면 설명란 맨 위에 대가 문구
[출처]
- [ ] 모든 수치에 출처, 확인 상태(✅/⚠️) 표시
- [ ] 설명란 참고 자료 목록 작성
```

## E. 광고·제휴 표시
- 대가를 받고 제품을 소개하면 **제목에 광고임을 표시**해야 하며, '더보기'를 눌러야 보이거나 댓글에만 쓴 표시는 부적절 (2020년 9월 개정 추천보증심사지침) ✅ [이투데이](https://www.etoday.co.kr/news/view/1909454)
- 문구 예: "광고", "유료광고 포함", "협찬". 제휴 링크는 설명란 맨 위에 "이 영상에는 제휴 링크가 포함되어 있으며, 구매 시 일정액의 수수료를 받습니다" ⚠️ 정확한 기준은 공정위 지침 원문과 제휴 플랫폼 정책 확인

## F. 기타
- **AI 기본법 (2026년 1월 22일 시행):** 표시 의무는 AI 서비스를 제공하는 사업자에게 있고, AI를 도구로 쓰는 유튜버는 제외 ✅ [헤럴드경제](https://www.heraldk.com/article/2026012021540608996)
- **TTS 라이선스:** 수익 영상은 대부분 유료 플랜 필요. 음성별 약관, 구독 종료 후 조건 확인 ⚠️ [Typecast](https://typecast.ai/kr/learn/free-vs-paid-tts-features-2026/)
- **레퍼런스 채널:** 포맷과 원리만 참고하고 대본·썸네일·캐릭터·채널명은 베끼지 않습니다.

# 오래 박사 채널 제작 키트: Claude Code 작업 지침

이 폴더는 **40~60대 한국인 대상 건강 + 경제 유튜브 채널**을 만드는 작업 공간입니다. 저장소 루트의 `watchCode`(Node CLI)와는 별개 프로젝트입니다.

## 채널 한 줄 요약
- 얼굴, 실제 전문가, 실제 목소리 없이 **캐릭터 일러스트 + TTS 내레이션**으로 만드는 근거 중심 건강·경제 잡학 채널입니다.
- 벤치마크는 일본 채널 「ウマい健康雑学」입니다. 포맷만 배우고 **한국 자료와 우리 캐릭터로 다시 만듭니다.**
- 출연진: **오래 박사**(사슴 마스코트, 내레이터의 얼굴, 마스터 이미지 `assets/characters/orae_master.png`), **50대 남성 주인공**(`man_sheet.png`), **50대 여성 주인공**(`woman_sheet.png`). 표정·포즈·아이콘도 `assets/characters/`에 있습니다.
- 채널명은 아직 정하지 않았습니다. 문서의 `[채널명]`은 자리표시자입니다.

## 작업 전에 읽을 문서 (순서대로)
1. `docs/03_포맷공식.md`: 주제 선정, 제목, 썸네일, 영상 구성 공식 **(가장 중요)**
2. `docs/04_내레이션가이드.md`: 말투, 훅, 항목 공식, 금지 표현, TTS
3. `docs/05_화면구성가이드.md`: 컷, 화면 요소, 자막
4. `docs/06_캐릭터바이블.md`: 캐릭터 설정과 이미지 프롬프트
5. `docs/09_장면이미지라이브러리.md`: 영상 장면 그림 목록과 한국식 프롬프트 틀
6. `docs/07_규정체크리스트.md`: 업로드 전 법·정책 점검
7. 근거 자료가 필요할 때: `docs/01_시장조사.md`, `docs/02_레퍼런스분석.md`, `docs/08_주제백로그.md`
8. 완성 예시: `episodes/001_커피/`

## 자주 하는 작업
| 요청 | 방법 |
|---|---|
| 새 에피소드 만들기 | `/episode <주제>` 스킬. 산출물은 `episodes/NNN_주제/` |
| 주제가 될지 검증 | `/topic-check <주제>` 스킬 |
| 만든 에피소드 검수 | `/episode-review <폴더>` 스킬 |
| 유튜브 수요 데이터 수집 | `python3 tools/yt.py ...`, `python3 tools/demand_scan.py ...` (사용법은 각 파일 상단) |
| 대본 길이 계산 | `python3 tools/duration.py <TTS원고.txt>` |

## 반드시 지킬 원칙
1. **근거 없이 숫자를 쓰지 않습니다.** 모든 수치에는 출처를 붙이고, 웹 검색으로 직접 확인했으면 ✅, 보도나 2차 자료로만 확인했으면 ⚠️로 표시합니다.
2. **단정하지 않습니다.** 관찰 연구는 "~와 관련이 있었다", "~경향이 있었다"로 씁니다. "치료된다", "낫는다", "거의 모두 ~된다"는 쓰지 않습니다.
3. **전문가를 사칭하지 않습니다.** 오래 박사는 '척척박사' 같은 캐릭터 별명입니다. 의사·약사로 보이게 하는 흰 가운, 청진기, 자격 표기는 넣지 않습니다.
4. **대본은 매번 새로 씁니다.** 제목과 썸네일 틀은 반복해도 되지만, 대본까지 틀에 단어만 바꿔 넣으면 YouTube 비진정성(대량생산) 정책에 걸립니다.
5. **한국 자료를 우선합니다.** 국민건강영양조사, 식약처, 질병관리청 국가건강정보포털, 한국소비자원, 국민연금공단, 국세청 등
6. **실존 브랜드 로고와 제품명은 화면에 쓰지 않습니다.** 일반 포장 그림으로 대신합니다.
7. **경제 편에서는 종목을 추천하지 않습니다.** 제도, 원리, 계산만 다룹니다. 유료 멤버십이나 리딩방은 만들지 않습니다.
8. 심장·약물처럼 위험이 있는 주제에는 "치료 중이면 담당 의사와 상의" 문장을 넣습니다.

## 산출물 저장 규칙
에피소드 폴더 `episodes/NNN_주제/` 안에 아래 파일을 만듭니다. 양식은 `templates/에피소드_패키지.md`에 있습니다.
- `00_기획.md`: 주제 검증 점수, 타깃, 제목 후보, 끝까지 보게 할 장치
- `01_리서치.md`: 사용할 연구와 수치, 출처, 확인 상태
- `02_제작대본.md`: 구성표, 구간별 화면 지시와 내레이션
- `03_TTS원고.txt`: 내레이션만
- `04_이미지프롬프트.md`: 썸네일과 장면별 이미지 생성 프롬프트
- `05_업로드정보.md`: 제목, 설명란(참고문헌, 고지 문구), 태그, 고정 댓글
- `06_검수.md`: 규정 체크리스트 결과와 남은 확인 사항

## 환경 메모
- 클라우드 환경에서는 **YouTube 영상과 자막 다운로드가 봇 확인으로 막힙니다.** 검색, 채널 목록, 영상 설명란, '가장 많이 다시 본 구간', 댓글은 `tools/yt.py`로 수집됩니다. 원고가 필요하면 사용자에게 YouTube의 '스크립트 표시' 내용을 복사해 달라고 요청합니다.
- 사용자와는 한국어로 대화합니다. 사용자는 개발자가 아니라 채널 운영자입니다. 결과는 쉽게 설명합니다.

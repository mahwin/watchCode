# 13. 숏츠 가이드

숏츠의 역할은 **구독자 모으기**입니다(`12_수익화전략.md`). 롱폼 1편에서 잡학 하나씩 뽑아 매일 1개 올리고, 원본 롱폼으로 연결합니다.

## 1. 레퍼런스 조사 (2026-10-19)
한국 YouTube 숏츠를 14개 검색어(건강 상식, 먹으면 안 되는 음식, 음식 궁합, 치매 예방, 혈당, 50대 건강, 노후 준비, 국민연금, 건강보험료, 커피 건강 등)로 찾아 조회수 상위 30개의 첫 화면을 봤습니다. 원본: `data/shorts_demand_raw.json`

| 검색어 | 100만 회 넘은 숏츠 | 최고 |
|---|---|---|
| 건강보험료 | 3개 | 763만 |
| 50대 건강 | 2개 | 719만 |
| 음식 궁합 | 7개 | 476만 |
| 먹으면 안 되는 음식 | 6개 | 444만 |
| 혈당 | 3개 | 424만 |
| 몸에 좋은 음식 | 6개 | 407만 |
| 커피 건강 | 2개 | 337만 |
| 노후 준비 | 4개 | 289만 |
| 치매 예방 | 3개 | 242만 |
| 국민연금 | 2개 | 136만 |

**얼굴 없이 만드는 채널도 수백만 회가 나옵니다.** 첫 화면 형태는 네 가지였습니다.

| 형태 | 예시 (조회수) | 우리에게 맞는 쓰임 |
|---|---|---|
| **말하는 캐릭터 애니메이션** | 사물의 참견 「착각하기 쉬운 건강 상식」 638만 — 음식·물건이 직접 말함 | 오래 박사와 부부 캐릭터로 같은 방식 |
| **목록을 한 화면에** | 바바라핵팁 「60대 이후 절대 먹으면 안되는 음식 7가지」 444만 — 첫 화면에 7개 목록 전체, 멈춰서 읽게 됨 | 정리 카드형 숏츠 |
| **사진·그림 + 큰 자막 3줄** | 건강이전부다! 「김 먹을때 같이 먹으면 안되는 음식 3가지」 266만, 꿀팁한상 「퇴사 후 따로 신청안하면 건보료 연금 폭탄」 724만 | 기본형 |
| **대결형 (A vs B)** | 어떤약사 「99%가 틀리는 혈당배틀」 361만 (사람 출연이지만 형식 참고) | 커피 판정, 음식 대결 |

참여형도 있습니다: 장수연구소 「30초 뇌운동 챌린지」 162만 → 퀴즈형 숏츠.

**따라 하지 않을 것:** 상위 숏츠 중에는 "의사들이 매일 먹습니다", "허준이 당부한", "하루 한 끼만으로 간이 살아나는", "귀 뒤에 바세린" 같은 **권위 빌리기와 근거 없는 단정**이 많습니다. 우리는 형식(큰 자막, 목록, 캐릭터, 대결)만 가져오고 주장은 근거와 출처로 합니다.

## 2. 규격
- 세로 9:16, 1080×1920. 길이 **30~50초** (짧을수록 끝까지 보게 하기 쉬움)
- **첫 화면이 썸네일입니다.** 위쪽 1/3에 큰 자막 2~3줄(줄당 8~12자, 흰색·노랑 + 검은 테두리, 핵심 단어만 빨강), 가운데 캐릭터 + 사물
- **가리는 곳 피하기:** 오른쪽 약 15%(좋아요·댓글 버튼)와 아래쪽 약 20%(제목·채널명)에는 중요한 글자를 두지 않음
- 자막은 화면 가운데~아래 사이, 한 번에 한 줄. 자동 자막은 꼭 고침
- 목소리는 롱폼과 같은 TTS 목소리, 배경음악은 작게

## 3. 구성 (40초 예시)
| 시간 | 내용 | 화면 |
|---|---|---|
| 0~2초 | **질문 훅** ("믹스커피, 하루 몇 봉까지 괜찮을까?") | 큰 자막 + 오래 박사 놀람·생각 낱장 |
| 2~8초 | 흔한 생각 ("한두 봉은 괜찮겠지?") | 남편 캐릭터가 믹스커피 타는 장면 |
| 8~30초 | **답** (숫자 하나 또는 3가지 목록). 출처는 화면 아래쪽 위에 작게 | 숫자 카드, 계산 카드 |
| 30~37초 | 한 줄 정리. 마지막 문장이 첫 질문으로 자연스럽게 이어지게 (다시 보기 유도) | 정리 카드 + 오래 박사 엄지척 |
| 37~40초 | "자세한 판정은 아래 영상에서" | 관련 동영상 연결 |

## 4. 우리 숏츠 종류
| 종류 | 예시 주제 | 나오는 롱폼 |
|---|---|---|
| 대결형 | 믹스커피 vs 아메리카노, 당이 더 적은 쪽은? | 001 커피 |
| 목록형 | 간이 지칠 때 확인할 것 3가지 | 004 간 |
| 돈 꿀팁형 | 퇴직 후 이것 안 하면 건보료가 오른다 (임의계속가입) | 005 건보료 |
| 퀴즈형 | 3초 안에 맞혀 보세요: ㄱㄱㅁ | 006 퀴즈 |
| 오해 바로잡기 | "빈속 커피는 위에 나쁘다?" | 001 커피 |

롱폼 1편에서 2~3개를 뽑되, **매번 새로 편집**합니다(같은 틀에 글자만 바꾸면 양산형 콘텐츠 위험).

## 5. 올릴 때
- **제목:** 훅 질문 그대로 (예: `믹스커피, 하루 몇 봉까지 괜찮을까?`). '#shorts'는 넣지 않아도 됨
- **설명:** 한두 줄 요약 + 출처 1~2개 + "AI 음성으로 제작, 대본은 직접 작성·검수"
- **해시태그 2~3개:** 주제어 + #건강정보 + #후반전잡학
- **관련 동영상:** 업로드 화면의 '관련 동영상'에 원본 롱폼 선택 (숏츠 화면에 링크가 뜸)
- 사실적인 AI 음성이면 '변경된 콘텐츠: 예'
- 매일 같은 시간대에 1개

## 6. 숏츠 제작 지시문 (서브에이전트용)
```
너는 유튜브 채널 '후반전 잡학'의 숏츠 담당이다. 첨부한 롱폼 제작서(또는 대본)와 이 가이드(13_숏츠가이드)만 보고 작업한다.
1) 롱폼에서 숏츠로 만들 잡학 3개를 고른다. 각각 근거와 출처가 롱폼 조사 칸에 있는 것만 고른다.
2) 숏츠마다 다음을 쓴다: 종류(대결형·목록형·돈 꿀팁형·퀴즈형·오해 바로잡기), 첫 화면 자막 2~3줄, 40초 이내 내레이션(가이드 3장 구성), 장면별 화면 지시(쓸 캐릭터 낱장 파일명 포함), 출처 자막, 제목, 설명 2줄, 해시태그 3개.
3) "의사들이 매일 먹는", "~가 살아난다", "무조건" 같은 권위 빌리기와 단정 표현을 쓰지 않는다. 숏츠 3개의 문장과 구성이 서로 겹치지 않게 쓴다.
4) 결과를 마크다운으로 돌려줘라.
```

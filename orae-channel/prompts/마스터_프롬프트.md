# 마스터 프롬프트

Claude Code에서 `/episode` 같은 명령이 안 보이거나, 다른 AI 도구에서 같은 방식으로 작업하고 싶을 때 아래를 통째로 붙여 넣으세요. `[ ]` 안만 바꾸면 됩니다.

---

## A. 새 에피소드 (Claude Code용)
```
orae-channel/CLAUDE.md와 docs 폴더 문서를 먼저 읽고, 그 지침대로 [주제] 편 에피소드 패키지를 만들어줘.

- 주제: [예: 계란]
- 타깃: [남성 / 여성 / 공통]
- 원하는 제목 형식: [없으면 알아서 / 예: 먹으면 안 되는 사람형]
- 추가로 꼭 다룰 내용: [없으면 비워 두기]

순서: 주제 검증(수요 측정 포함) → 리서치(한국 자료 2개 이상, 출처와 확인 상태 표시) → 대본(14~17분, 다큐체) → 화면 지시 → 이미지 프롬프트 → 업로드 정보 → 검수.
결과는 orae-channel/episodes/ 아래 새 폴더에 파일 7개로 저장하고, 끝나면 제목, 길이, 내가 직접 할 일을 짧게 알려줘.
```

## B. 주제 추천
```
orae-channel/docs/03_포맷공식.md와 08_주제백로그.md를 읽고, 다음에 만들 주제 5개를 추천해줘.
tools/demand_scan.py로 한국 유튜브 수요를 실제로 측정하고, 체크리스트 점수와 추천 제목 형식을 표로 보여줘.
조건: [예: 여성 타깃 2개 포함 / 경제 주제 1개 포함]
```

## C. 검수
```
orae-channel/episodes/[폴더명]을 docs/07_규정체크리스트.md 기준으로 검수해줘.
의료·광고·AI 표시·경제 규정, 수치와 출처, 금지 표현, 길이(tools/duration.py), 포맷 공식 준수를 점검하고
06_검수.md에 결과를 쓴 다음, 바로 고칠 것과 내가 직접 확인할 것을 나눠서 알려줘.
```

## D. 레퍼런스·경쟁 채널 추가 조사
```
orae-channel/tools/yt.py로 [채널 핸들 또는 검색어]를 조사해줘.
최신·인기 영상 목록, 상위 영상 3개의 설명란과 '가장 많이 다시 본 구간', 댓글 반응을 모아서
docs/02_레퍼런스분석.md와 같은 형식으로 정리하고, 우리 공식(docs/03_포맷공식.md)에 반영할 점을 제안해줘.
영상 원고가 필요하면 나에게 YouTube '스크립트 표시' 내용을 복사해 달라고 요청해줘.
```

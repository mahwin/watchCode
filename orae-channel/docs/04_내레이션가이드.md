# 04. 내레이션 가이드

목소리의 주인은 **오래 박사**입니다. 차분하고 다정하며, 과장을 싫어하고 근거를 꼼꼼히 확인하는 선배 톤입니다.

## 1. 말투
- 본문: **다큐체(~다, ~이다)**. 「생로병사의 비밀」 내레이션 같은 권위 있는 톤
- 질문형 전환: "~일까?", "~살펴보자"
- 마지막 인사만 존댓말: "구독과 좋아요 부탁드립니다."
- 문장은 짧게. 한 문장에 정보 하나. 4060이 귀로만 들어도 이해되게 씁니다.

## 2. 훅 공식 (60초 안팎, 5단계)
1. **상황 맞히기:** "잠 깨려고 아침에 한 잔. 점심 먹고 한 잔. 지금 이 영상을 보는 당신도 하루 두세 잔은 마시고 있지 않은가?"
2. **상식 뒤집기:** "그런데 커피는 그저 잠 깨는 음료가 아니다."
3. **판 키우기 + 최신성:** "최근 연구들은 커피와 간, 혈당, 심장, 뇌의 관계까지 들여다보고 있다."
4. **경고:** "다만 어떻게 타서 마시느냐에 따라 오히려 몸에 부담이 될 수도 있다."
5. **목차 + 열린 고리:** "오늘은 ~ 여섯 가지, ~ 세 가지, 그리고 마지막으로 효과를 높이는 마시는 시간까지 알아보자."

## 3. 항목 공식 (항목당 40~60초)
1. 번호와 제목: "두 번째, 혈당."
2. 배경: 해당 장기나 상황을 쉬운 말로 한두 문장
3. 연구: 연도, 대상 규모 ("118만 명 이상을 분석한 연구에서")
4. 숫자: "약 6%씩 낮아지는 경향" (관찰 연구는 반드시 '경향', '관련')
5. 이유: 왜 그런지 한 문장
6. 반전이나 한국 자료: "흥미롭게도 디카페인에서도…", "한국인 연구도 있다."
7. (선택) 다음 구간 예고: "이 이야기는 뒤에서 다시 나온다."

## 4. 전환 문장 모음
| 상황 | 문장 |
|---|---|
| 기초 → 효과 | 그렇다면 ○○를 오래 먹어 온 사람들의 몸에는 어떤 차이가 있을까? |
| 제목 답 공개 | 결론부터 말하면, 연구에서 가장 꾸준히 차이가 나타난 곳은 ○○다. |
| 다시 붙잡기 | 여기까지 들으면 오늘부터 ○○를 더 먹고 싶어졌을지도 모른다. 하지만 좋은 연구가 많은 만큼, 잘못 먹으면 그 효과를 스스로 깎아 먹게 된다. |
| 고르는 법 | 그렇다면 매일 먹는 ○○, 어떻게 골라야 할까? |
| 함께 먹을 것 | 나에게 맞는 ○○를 골랐다면, 이제 무엇과 함께 먹을지 생각해 보자. |
| 마지막 공개 | 그런데 처음에 말한 가장 중요한 포인트가 하나 남았다. |
| 앞 내용 불러오기 | 앞에서 본 '○○'라는 단어를 기억하자. |
| 주의 | 잠깐, 여기서 많이들 실수한다. |

## 5. 마무리 공식
1. 한 문장 정리: "중요한 건 억지로 양을 늘리는 게 아니라, 무엇을 넣고 언제 먹느냐다."
2. 3줄 요약: "오늘 내용을 정리하면 세 가지다. ~. ~. 그리고 ~."
3. 댓글 질문: "여러분은 ○○를 어떻게 드시는지 댓글로 알려 주세요."
4. 구독 요청 (존댓말, 한 번만)
5. **시그니처:** "오늘 배운 잡학으로, 오래오래 건강하게. 오래 박사였습니다."

## 6. 쉬운 말로 바꾸기
| 피할 말 | 바꿀 말 |
|---|---|
| 클로로겐산, 폴리페놀 | 커피 속 항산화 성분 (처음 한 번만 이름 소개) |
| 메타분석 | 여러 연구를 묶어 분석한 연구 |
| 무작위 대조 임상시험 | 사람들을 두 그룹으로 나눠 비교한 실험 |
| 상대위험도 0.72 | 위험이 약 28% 낮았다 |
| 인슐린 저항성 | 혈당을 낮추는 힘이 떨어진 상태, 당뇨로 가는 길목 |
| 섬유화 | 간이 점점 딱딱하게 굳는 것 |
| 아데노신 A2A 수용체 | (빼거나) 뇌의 신호 |

## 7. 금지 표현과 대체 표현
| 금지 | 대체 |
|---|---|
| ○○ 먹으면 당뇨가 낫는다 / 완치 | ○○를 먹는 사람에게서 당뇨 위험이 낮은 경향이 있었다 |
| 약 끊어도 된다 | 약은 담당 의사와 상의 없이 바꾸지 말자 |
| 거의 모든 사람이 ~된다 | 연구에서 ~한 사람이 많았다 |
| 의사들이 숨기는 / 병원이 말 안 하는 | (쓰지 않음) |
| 이것만 먹으면 | ○○와 함께 생활습관도 중요하다 |
| 저는 의사로서 | (오래 박사는 자격을 말하지 않음) |
| ○○ 종목 사세요 | 이 제도는 이렇게 계산된다 |

## 8. TTS 설정
- **속도:** 기본의 0.9배 안팎. 4060 시청자에게 맞추되, 너무 느리면 "2배속 안 하면 잠든다"는 반응이 나옵니다(레퍼런스 댓글).
- **쉼:** 문장 끝 0.3~0.5초, 구간 전환 1초. 숫자 앞에서 아주 짧게 끊으면 귀에 잘 들어옵니다.
- **목소리:** 중저음 남성, 차분하고 따뜻한 톤. 영상마다 같은 목소리로 고정합니다.
- **숫자 읽기:** "118만" 같은 표기가 이상하게 읽히면 원고에 "백십팔만"처럼 한글로 고칩니다. 업로드 전에 반드시 전체를 들어 봅니다.
- **라이선스:** 수익이 나는 유튜브에는 대부분 **유료 플랜**이 필요합니다. 음성마다 약관이 다르고, 구독을 끊으면 상업 이용이 안 되는 조건도 있으니 가입 전 공식 약관을 확인합니다 ⚠️ [Typecast 안내](https://typecast.ai/kr/learn/free-vs-paid-tts-features-2026/)
- **표시:** 사람과 구분하기 어려운 사실적 목소리라면 업로드할 때 '변경된 콘텐츠'를 '예'로 표시하고, 설명란에 "AI 음성으로 제작, 대본은 직접 작성·검수"를 적습니다.

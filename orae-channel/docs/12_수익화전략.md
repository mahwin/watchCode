# 12. 수익화 전략: 숏츠로 구독자, 롱폼으로 시청 시간

2026-10-19 정리. 규정은 자주 바뀌니 유튜브 스튜디오의 '수익 창출' 탭에서 다시 확인합니다.

## 1. 수익 창출(YPP) 기준
| 항목 | 지금 (2027년 1월 31일까지 신청) | 2027년 2월 1일부터 신규 신청 | 확인 |
|---|---|---|---|
| 구독자 | 1,000명 | 1,000명 | ✅ |
| 롱폼 경로 | 최근 12개월 공개 시청 시간 **4,000시간** | **8,000시간** | ✅ 공식 / ⚠️ 변경은 보도 기준 |
| 숏츠 경로 | 최근 90일 숏츠 조회수 **1,000만 회** | **2,000만 회** | ✅ 공식 / ⚠️ 변경은 보도 기준 |

- **숏츠 피드에서 본 시간은 4,000시간에 들어가지 않습니다.** ✅ [유튜브 고객센터](https://support.google.com/youtube/answer/72851)
- **구독자는 숏츠로 왔든 롱폼으로 왔든 똑같이 1,000명에 들어갑니다.**
- 2027년 2월 기준 상향은 유튜브가 2026년 8월 10일 발표했다는 보도로 확인했습니다. 이미 가입한 채널은 영향이 없습니다. ⚠️ [Shacknews](https://www.shacknews.com/article/150324/youtube-partner-program-minimum-qualified-public-watch-hours-shorts-views), [루트노트](https://routenote.com/kr/blog/?p=2754), [미코(더버지 보도 인용)](https://meeco.kr/news/41804326)
- 숏츠 광고 수익은 1,000회당 몇 센트 수준이라는 글이 많습니다(블로그 기준이라 ⚠️). 숏츠는 **돈을 버는 곳이 아니라 구독자를 데려오는 곳**으로 봅니다.

## 2. 역할 나누기
| | 숏츠 | 롱폼 |
|---|---|---|
| 목표 | 구독자 1,000명 | 시청 시간 4,000시간 |
| 길이 | 30~50초 | 14~17분 (퀴즈 8~12분), 몰아 듣기 1~2시간 |
| 내용 | 잡학 하나 + 답 공개 | 제작서 기준 전체 구성 |
| 연결 | 숏츠 편집 화면의 '관련 동영상'에 원본 롱폼 연결, 마지막 말 "자세한 건 아래 영상에서" | 최종 화면에 다음 영상·재생목록 |

## 3. 2027년 1월 31일까지 목표 (약 15주)
- 4,000시간 = 24만 분. 평균 시청 시간이 4~6분이라고 가정하면 롱폼 조회수 **4만~6만 회**가 필요합니다(가정이라 실제 평균 시청 시간은 스튜디오에서 확인).
- 몰아 듣기(1~2시간 묶음)는 한 번 볼 때 시청 시간이 길어 시간을 채우는 데 유리합니다. 우리 영상만 묶고, 채널의 대부분은 새 영상으로 채웁니다(양산형으로 보이지 않게).
- 기한을 넘기면 8,000시간이 필요해져 두 배 어려워집니다.

## 4. 운영 리듬 (제안)
| 주기 | 할 일 |
|---|---|
| 주 2편 | 롱폼 (형식 번갈아: 음식 → 신호 → 돈 → 퀴즈) |
| 매일 1개 | 숏츠. 롱폼 1편에서 2~3개를 뽑고 매번 새로 편집(같은 틀에 글자만 바꾸지 않음) |
| 6편 쌓이면 | 몰아 듣기 1편, 이후 2~3주마다 |
| 매주 | 스튜디오에서 구독자, 공개 시청 시간(수익 창출 탭 진행률), 숏츠의 관련 동영상 클릭 수 확인 |

## 5. 숏츠 만드는 법
- 세로 9:16, 첫 2초 안에 질문 ("커피, 이 시간에 마시면 다릅니다")
- 자막은 크게, 캐릭터 낱장을 화면 아래쪽에 크게
- 잡학 하나만. 답은 끝에서 공개하고 근거 출처를 작게 표시
- 원칙은 롱폼과 같음: 단정 금지, 출처 표시, 레퍼런스 원고 번역 금지

## 6. 주의
- 숏츠로 온 구독자는 롱폼을 잘 보지 않는 경우가 많다고 알려져 있습니다. 그래서 숏츠 주제를 **롱폼과 같은 주제로** 맞추고 관련 동영상을 꼭 연결합니다.
- 수익 창출 심사에서는 채널 전체가 원본 콘텐츠인지 봅니다. 001 커피 편처럼 레퍼런스와 너무 비슷한 영상은 심사 전에 정리합니다.
- 실제 인물을 흉내 낸 AI가 의료·금융 조언을 하면 수익 제외 대상입니다(`07_규정체크리스트.md`). 우리 캐릭터는 그림 캐릭터이고 실존 인물을 흉내 내지 않습니다.

# EP013 「따로 계산」 (현실 톤 악역 + 사이다)

**제목:** "이 친구 건 따로 계산해 주세요" 부도난 친구를 대놓고 망신 준 동창… 잠시 후 직원의 한마디에 얼어붙었다 #시니어드라마 #시니어쇼츠 #시니어 #반전드라마
**로그라인:** 15년 만의 동창 모임. 선영은 남편 부도 뒤 사라졌던 춘희를 "야반도주한 애"라고 부르고, 직원에게 "이 친구 건 따로 계산해 달라"며 모두 앞에서 망신을 준다. 계산서를 가져온 직원이 말한다. "이분이 룸 전체 계산하셨어요. 한 분 것만 빼고요." 그리고 15년 전 소문을 낸 사람이 누구였는지 드러난다.
**톤:** 악역은 확실히 나쁘게, 하지만 현실에서 실제로 할 법한 말로만. 자랑 릴레이, "대표님!" 인사, 효과음 개그는 없어요.
**반전:** ① 춘희가 선영 것만 빼고 전부 계산함 ("따로 계산하자며") ② 춘희는 이 식당 반찬을 대는 공장 대표, 선영이 먹던 장아찌도 춘희가 담근 것 ③ 15년 전 "야반도주" 소문을 퍼뜨린 사람이 선영이었고, 은주도 알고 있었음
**길이:** 약 1분 50초

## 등장인물
| id | 이름 | 설명 |
|---|---|---|
| C1 | 춘희 (62) | 15년 전 남편 부도. 지금은 반찬 납품 회사 운영. 말수가 적고 침착함 |
| C2 | 선영 (62) | 모임 주도. 웃으면서 찌르는 사람. 15년 전 소문의 주인공 |
| C3 | 은주 (62) | 선영 옆에서 눈치 보던 친구. 마지막에 춘희 편에 섬 |
| C4 | 사장 (50대) | 한정식집 사장. 춘희 회사와 10년째 거래 중 |

## 나레이션

```
[0초 / 고급 한정식집 룸. 선영과 은주가 앉아 있고, 작업 조끼 차림의 춘희가 막 앉으려 한다]
선영: (코를 막고 물티슈를 춘희 쪽으로 툭 던지며) 어머, 어디서 쉰내 나지 않니? 아, 네 작업복이구나.
[춘희가 움찔하며 거친 손을 식탁 아래로 숨긴다]
은주: 내가 불렀어. 근처서 일하다 왔대.
선영: (금박 청첩장을 식탁 위로 휙 던지며) 우리 딸 시집가. 넌 축의금 하지 마. 부담되잖아. (입을 가리고 풉)
춘희: (청첩장을 조용히 바로 놓으며) …축하해.

[14초 / 주문하면서 공개 망신]
[식당 사장이 직접 주문을 받으러 들어온다]
사장: 어서 오세요. 주문 도와드릴게요.
선영: (사장에게, 다 들리게) 한우 코스 셋이요. 얘 거는 따로 선불로 받으세요. 도망간 전적이 있거든요.
사장: (춘희를 보고 멈칫) 대… 네?
[춘희가 아주 작게 고개를 젓는다]
사장: (정중히) 결제는 식사 후에 도와드리겠습니다.
은주: 선영아, 말 좀 가려서 해…
선영: 사실이잖아.

[28초 / 한상 차려진 식탁, 찌르기]
선영: (장아찌를 맛있게 집어 먹으며) 여기 VIP 아니면 예약도 안 돼. 이 장아찌가 명물이야.
선영: 넌 요즘 뭐 먹고 사니?
춘희: 반찬 납품해.
선영: (춘희 손을 훑어보며) 어머, 남의 집 찬모 노릇? 어쩐지 손톱 밑이 시커멓더라.
선영: (먹던 장아찌를 내려놓으며) 갑자기 입맛 떨어지네.
선영: 너 그때 망하고 동창들한테 돈 꾸러 다녔잖아. 나한테도 왔었지?
춘희: (똑바로 보며) 응. 은주 돈은 다 갚았어. 너만 안 빌려줬지.
[정적]

[48초 / 춘희가 나가고, 최고 긴장]
춘희: (냅킨을 접어 놓고 일어서며) 화장실 좀.
선영: (깔깔) 봐, 계산할 때 되니까 또 도망가잖아.
은주: 너 오늘 말 너무 막 한다.
선영: 심하긴. 주제를 알아야지. (사장을 불러 느긋하게) 사장님, 우리 둘 거만 계산서 주세요.

[60초 / 반전 ①]
[춘희가 돌아와 앉지 않고 가방을 챙겨 든다]
사장: 저… 방금 이분이 카운터에서 계산하셨어요. 한 분 것만 빼고요.
선영: …한 사람이 누군데요?
사장: (선영 앞에 계산서를 내려놓으며) 손님 거요.
춘희: 따로 계산하자며. 그래서 너만 따로 했어.

[72초 / 반전 ②]
선영: (코웃음) 네가 돈이 어디 있어서?
사장: (춘희에게 고개 숙이며) 모르셨어요? 저희 거래처 대표님이세요. 저희 집 반찬, 다 대표님 공장에서 들어와요.
선영: 대… 대표?
춘희: (거친 두 손을 식탁 위에 짚으며) 네가 명물이라던 그 장아찌, 이 손으로 담근 거야.
[은주가 놀라 춘희를 보다가, 피식 웃는다]

[86초 / 반전 ③]
춘희: 15년 전에, 나 도망간 거 아니야.
[회상 3초, 대사 없음: 새벽 시장 바닥, 입김이 나는 추위 속에서 김치 통을 늘어놓고 파는 젊은 춘희]
춘희: 남편 빚 갚으려고, 새벽마다 시장 바닥에서 김치 팔았어.
춘희: 그런데 "춘희네 야반도주했다"는 소문이 돌더니, 김치 받던 가게들이 하루아침에 다 끊더라.
[선영이 눈을 피한다]
은주: (선영을 보며) …그 소문, 너였잖아. 동창들한테 전화 다 돌린 거.
선영: 그, 그건… 다들 그렇게 말하길래…
춘희: (청첩장을 선영 쪽으로 밀어 주며) 축의금은 안 할게. 네 말대로.
춘희: 망한 건 창피한 게 아니더라. 망한 친구 짓밟는 게 창피한 거지.
춘희: 은주야, 커피 마시러 가자.
[둘이 나간다]

[106초 / 결말]
사장: (혼자 남은 선영에게) 손님 몫 십오만 원입니다. 카드로 하시겠어요?
선영: (떨리는 목소리로) …VIP 할인은 되죠?
사장: 저희 가게는 원래 VIP가 없어요.
[선영이 얼어붙는다 → 정지 화면]

[115초 / 엔딩 자막]
"사람 형편은 15년이면 바뀝니다. 사람 됨됨이는 잘 안 바뀌고요."
```

## 작가 노트
- **악역은 세게, 말은 현실적으로:**
  - "야반도주했던 애", "살아 있었네?", "이 친구 건 따로 계산해 주세요", "남의 집 부엌일", "형편 안 되면 안 나오는 게 예의야"
  - 전부 실제 모임에서 누군가 할 법한 말이에요. 과장된 악다구니 없이, 웃으면서 찔러서 더 얄미워요.
- **후킹:** 첫 줄부터 "부도나고 야반도주했던 애", 둘째 줄에서 "또 도망갈걸?"이 나와요. 16초에 직원 앞 공개 망신까지 가서 20초 안에 갈등이 끝까지 올라가요. 썸네일·제목도 "따로 계산해 주세요" 장면이에요.
- **개연성:** "따로 계산"은 주문할 때 자연스럽게 나오고, 춘희는 화장실 가는 척 나가 카운터에서 계산해요. 직원은 선영이 계산서를 달라고 할 때 말해요.
- **반전 ①은 악역의 말을 그대로 돌려줘요.** 선영이 망신 주려고 한 "따로 계산"을, 춘희가 그대로 실행해요. 회장이나 대표 신분 공개 없이 영수증 한 장으로 끝나요.
- **반전 ②는 과거의 죄예요.** 선영은 그냥 무례한 사람이 아니라, 15년 전 소문으로 춘희의 거래처를 끊게 만든 사람이에요. 방관하던 은주가 그걸 증언하면서 편이 바뀌어요.
- **처벌은 현실적으로:** 경찰도, 남편 회사 몰락도 없어요. 친구가 떠나고, 혼자 계산서 앞에 남는 것이 벌이에요.
- **명대사:** "따로 계산하자며. 그래서 너만 따로 했어." / "망한 건 창피한 게 아니더라. 망한 사람 비웃는 게 창피한 거지."
- **배경음악:** 0~62초 긴장감 있는 단조 피아노, 46~62초와 80~96초에서 3~6dB 더 낮춰요. 62초 "손님 거요" 직후에는 대사 없이 1~2초 정적 연기를 두되 음악은 끊지 않고, 96초부터 장조 피아노로 바꿔요.

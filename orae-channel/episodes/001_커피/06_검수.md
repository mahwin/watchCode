# 001. 커피 검수

## 체크리스트
- [ ] 사람과 거의 같은 TTS를 쓰면 업로드할 때 '변경된 콘텐츠'에 '예' 표시
- [ ] 썸네일과 화면에 실존 브랜드 로고 없음
- [ ] '치료된다·낫는다' 같은 단정 표현 없음
- [ ] 심장 구간의 '담당 의사와 상의' 자막 확인
- [ ] 설명란 참고 자료와 안내 문구 붙여넣기

## 확인 상태 요약
| 상태 | 자료 |
|---|---|
| ✅ 이번에 검색으로 확인 | 마시는 시간(European Heart Journal 2025), DECAF(JAMA), 터프츠대(J Nutr 2025), 사무실 커피머신(2025), 식약처 400mg·커피전문점 평균 132mg(2019 조사), 커피믹스 당류 5.7g(소비자원 2014), 한국인 연간 405잔(유로모니터 2023) |
| ⚠️ 언론 보도로만 확인, 원논문 확인 필요 | 경희대 Nutrients 2025(여성 인슐린 저항성 30% 가까이↓), 2007~2011 국민건강영양조사 분석(대사증후군 1.25배·믹스커피 96%), 이화여대 연구(믹스·블랙 차이 없음) |
| ⚠️ 레퍼런스 채널 설명란 또는 기존 지식 기반, 원문 확인 권장 | 간 섬유화(2021), 2형 당뇨(2018), 사망 위험(2019), 파킨슨(2014), 장내 세균(2024), 수면 36분(NEJM 2023), PREDIMED(2018), 카카오·혈압(코크란 2017), WHO 25g |

## 남은 확인 사항
- [ ] ⚠️ 경희대 Nutrients 2025, 2007~2011 국민건강영양조사 분석, 이화여대 연구의 원논문 확인
- [ ] ⚠️ 레퍼런스 설명란 기준 자료(간, 당뇨, 사망, 파킨슨, 장내 세균, 수면)를 PubMed에서 한 번씩 확인
- [ ] 커피믹스 당류는 2014년 조사이므로 현재 판매 제품 포장의 영양성분표로 확인
- [ ] TTS로 숫자 읽기("118만", "3.5잔", "400mg") 직접 들어 보기

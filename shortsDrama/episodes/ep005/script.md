# EP005 「손수건」

**제목:** 청소부를 무릎 꿇린 사모님… 아들을 살릴 유일한 기증자가 그 청소부였다
**로그라인:** 아들 자랑이 입에 붙은 사모님이 백화점에서 청소부를 무릎 꿇린다. 석 달 뒤 아들이 백혈병으로 쓰러지고, 유전자가 맞는 단 한 명의 기증자가 바로 그 청소부였다. 청소부는 거절을 선언하지만, 그날 엄마 대신 고개 숙였던 아들의 손수건을 꺼내 든다.
**원안:** 사용자 플롯 ("막 대한 사람이 하필 자식의 유일한 기증자")
**바꾼 점:**
- 결말: 거절해서 자식이 죽는 결말 → "거절하겠습니다"로 시원함을 준 뒤, 아들 때문에 기증하는 결말
- 장기이식 → 조혈모세포(골수) 기증. 모르는 사람끼리 유전자가 맞으면 기증할 수 있어요
- 기증자 신원은 법으로 공개가 금지돼 있어서, 엄마의 **큰 목소리로 하는 자랑**을 기증자가 우연히 듣는 방식으로 정체를 알게 해요 (성격이 곧 반전 장치)

**길이:** 약 125초

| C1 | 영순 (60) | 피해자 → 기증자 | 백화점 청소부. 말수가 적고 단단해요. 사원증 줄에 작은 '생명나눔' 배지 |
| C2 | 혜숙 (58) | 가해자 | 강남 사모님. 입만 열면 "우리 지훈이" 자랑 |

| C4 | 코디네이터 (30대) | 전화 목소리 | 조혈모세포 기증 코디네이터 |

**복선 소품:** 지훈이 영순에게 건넨 하늘색 손수건, 영순의 사원증 줄에 달린 '생명나눔' 배지

## 자가 점검
- [x] 첫 대사가 갈등인가? → "무릎 꿇고 닦아!"
- [x] 피해자에게 잘못이 없는가? → 카트가 살짝 부딪힌 실수에 즉시 사과했고, 끝까지 품위를 지켜요
- [x] 복선이 40초 이전에 나오고 회수되는가? → 16초 손수건과 '생명나눔' 배지 → 92초 손수건, 62초 기증자 정체
- [x] 반전 직전이 가장 심한 순간인가? → 병원에서도 "여기도 청소해?" 하고 비웃은 직후 정체가 드러나요
- [x] 구원자가 한 명 이하인가? → 구원자 없이 피해자 본인이 칼자루를 쥐어요
- [x] 결말이 사과와 해소로 끝나는가? → 거절(시원함) → 기증(품위) → 1년 뒤 사과(해소)
- [x] 3분 이내인가? → 약 125초

## 작가 노트
- **시원함이 두 번 터져요.**
  1. "거절하겠습니다" — 시청자가 가장 듣고 싶었던 말이에요.
  2. 똑같은 무릎 꿇기 + "무릎 꿇는 거, 생각보다 아프죠?" — 되갚기예요.
- **기증하는 이유를 미리 깔아 뒀어요.** 16초에 아들이 엄마 대신 사과하는 장면이 있어서, 영순이 마음을 바꾸는 게 갑작스럽지 않아요. 시청자도 "그 아들이라서 살린다"에 납득해요.
- **엄마에게 가장 아픈 벌:** "그 아이가 당신을 닮지 않길 바랄게요." 자식을 잃는 것보다, 자기가 그렇게 자랑하던 자식이 자기와 정반대라는 걸 확인하는 게 이 인물에게는 더 큰 벌이에요.
- **엄마의 자랑이 반전 장치예요.** 기증자 신원은 비공개가 원칙이라, 혜숙이 병원 로비에서 떠벌린 자랑을 영순이 우연히 듣게 했어요. 인물의 결함이 그대로 이야기를 움직여요.
- **엔딩 질문:** "여러분이라면 기증하셨을까요?"는 찬반이 갈려서 댓글이 많이 달릴 질문이에요.
- **현실성 메모:** 국내에서는 기증자와 수혜자의 신원 공개가 법으로 금지돼 있고, 기증을 신청했다가 막판에 철회하는 사례도 실제로 많이 보도됐어요. 철회 가능 시점 같은 세부 절차는 이 대본에서 다루지 않아요.
- **배경음악:** 0~32초는 단조 피아노, 32~92초는 더 무거운 단조(첼로가 들어간 곡), 92초 손수건부터 장조 피아노와 현악기로 바꿔요. 72~82초("거절하겠습니다")와 102~110초(마지막 한마디)에서 음악을 더 낮춰요.

# 06. 검수 · 편집 · 렌더링 가이드

## 6-1. 이미지 검수 (영상 생성 전에 반드시)
영상 생성은 비싸니까 **이미지 단계에서 걸러야** 해요.

| 항목 | 불합격 기준 |
|---|---|
| 얼굴 일관성 | 캐릭터 시트와 다른 사람처럼 보임 |
| 의상 일관성 | 진주가 사라짐, 작업복 색이 바뀜 |
| 손·손가락 | 6개, 녹아내림, 물건과 합쳐짐 |
| 글자 | 이미지 안에 깨진 글자나 간판 (명찰 클로즈업은 편집에서 글자를 합성) |
| 장소 일관성 | 같은 룸인데 벽지나 조명이 다름 |
| 감정 | 대사 감정과 표정이 다름 (화내야 하는데 웃음) |

## 6-2. 영상 검수 (MODE A)
| 항목 | 불합격 기준 |
|---|---|
| 립싱크 | 입 모양과 대사가 0.3초 이상 어긋남 |
| 한국어 발음 | 단어가 뭉개지거나 외국어 억양 |
| 화자 혼동 | 다른 인물이 대사를 말함 |
| 모핑 | 얼굴이나 손이 중간에 변형됨 |
| 불필요한 음악·자막 | 모델이 음악이나 자막을 넣음 |

→ 불합격 컷은 프롬프트를 고쳐서 다시 생성해요. 같은 컷을 3번 실패하면 컷을 둘로 쪼개거나 MODE B(이미지 + TTS)로 대체해요.

## 6-3. 편집 규칙 (CapCut / Vrew / Premiere)
- **자막:** 세로 중앙보다 살짝 아래, 흰 글씨에 검은 테두리, 굵은 고딕, 한 줄 15자 내외, 최대 2줄
- **워터마크:** 채널명은 우측 상단. 생성 툴 워터마크가 있으면 그쪽을 피해서 배치
- **효과음:** 반전 순간에 "헉", 물건 떨어질 때 "툭", 해소 장면에 "박수"
- **음악:** 갈등 구간은 낮은 긴장감 피아노, 반전 이후는 따뜻한 스트링. 대사보다 -18dB 이상 작게
- **컷 전환:** 하드컷만 사용 (디졸브나 화려한 전환은 금지). 반전 컷 직전에만 0.3초 무음
- **MODE B 모션:** 컷마다 줌 5~8%, 반전 컷만 흔들림 효과
- **엔딩:** 마지막 2초에 댓글 유도 질문 자막

## 6-4. 최종 렌더링
- 1080x1920, 30fps, H.264, 오디오 AAC 48kHz
- 길이 110~125초
- 파일명: `ep{번호}_{제목 요약}.mp4`

# EP004 「문 안까지」 (공식편)

**제목:** 명절에 택배기사 사위만 부엌에 세운 장모님… 잠시 후 도착한 택배 상자에 대반전
**로그라인:** 추석날 장모는 의사 큰사위를 상석에 앉히고, 택배기사 작은사위는 부엌일만 시킨다. 그때 장모 앞으로 택배 상자가 도착한다. 장모가 가족 몰래 숨겨 온 무릎 병을 알아챈 사람은 의사 사위가 아니라 택배기사 사위였다.
**선정 이유:** backlog B04(20/25)를 다듬었어요. 레퍼런스 고성과 키워드인 명절(170만)을 쓰고, 반전 유형을 **"숨은 은인"(1편), "가해자의 잘못"(2편)과 다른 "무시당한 사람만 알고 있던 진실"**로 잡아서 앞 편들과 겹치지 않아요. 가해자도 시어머니가 아닌 **장모**로 바꿨어요.
**길이:** 약 120초

## 등장인물
| id | 이름 | 역할 | 설명 |
|---|---|---|---|
| C1 | 준호 (38) | 피해자 | 택배기사인 작은사위. 말수가 적고 성실해요. 명절에도 작업 점퍼 차림 |
| C2 | 영자 (66) | 가해자 | 장모. 체면을 중시해요. 걸을 때 오른쪽 무릎을 살짝 절어요 (가족은 모름) |
| C3 | 성민 (42) | 조연 악역 | 의사인 큰사위. 상석에 앉아 거들먹거려요 |
| C4 | 수진 (35) | 준호의 아내 | 엄마와 남편 사이에서 눈치를 봐요 |
| C5 | 택배기사 동료 (40대) | 반전 전달 | 준호의 동료. 상자를 배달하러 와요 |

**복선 소품:** 영자가 숨겨 둔 파스, 영자가 절룩이는 걸음, 준호가 영자의 무릎을 흘끗 보는 시선

## 대본

```
[0초 / 명절 처가 거실. 큰상 앞, 영자가 준호를 막아선다]
영자: 자네는 거기 앉지 말고 부엌 가서 전이나 부쳐. 상석은 의사 선생 자리야.
준호: (조용히) 네, 장모님.

[8초]
성민: (상석에 앉으며 웃음) 아이고, 장모님. 동서도 같이 앉지 그러세요.
영자: 됐어. 명절에 택배나 나르는 사람이 무슨 상석이야.
수진: 엄마…!

[18초 / 복선 ①]
[영자가 갈비 접시를 들고 성민 쪽으로 걸어간다. 오른쪽 무릎을 살짝 절뚝인다]
[부엌 입구의 준호가 영자의 무릎을 흘끗 본다. 표정이 굳는다]
영자: (성민에게 갈비를 덜어 주며) 우리 큰사위는 병원에서 고생 많지? 많이 먹어.

[30초 / 복선 ②]
[부엌. 준호가 전을 부치다 서랍을 연다. 파스 수십 장이 숨겨져 있다]
[준호가 말없이 서랍을 닫는다]
수진: (부엌으로 들어오며) 여보, 미안해. 엄마가 원래…
준호: 괜찮아. 장모님 요즘 계단 많이 다니셔?
수진: 엄마? 몰라. 왜?
준호: …아니야.

[45초]
영자: (거실에서) 작은사위! 자네가 가져온 이건 뭐야?
[준호가 들고 온 사과 상자를 영자가 발로 툭 민다]
영자: 큰사위는 홍삼을 가져왔는데, 자네는 과일 한 상자야?
성민: (웃음) 장모님, 동서 형편도 생각해 주셔야죠.

[58초 / 최고 긴장]
영자: 형편? 그러니까 내가 처음부터 이 결혼 반대했잖아.
영자: 남의 집 문 앞에 상자나 던지고 다니는 사람이 우리 집 사위라니, 창피해서 원.
수진: 엄마, 그만해! 명절에 꼭 이래야 돼?
준호: (수진의 손을 잡으며, 조용히) 괜찮아.

[70초 / 반전]
[초인종. 준호의 동료 택배기사가 상자를 들고 서 있다]
동료: 김영자 님 앞으로 온 택배입니다. 준호야, 너 쉬는 날이라 내가 들고 왔다.
영자: 나한테? 난 시킨 거 없는데.
[영자가 상자를 연다. 무릎 보호대, 지팡이 의자, 그리고 서류 한 장]
영자: (서류를 읽다가 굳는다) …정형외과 수술 예약 확인서? 수술비… 완납?  [헉]

[85초]
수진: 엄마… 무릎 수술이라니, 이게 무슨 소리야?
영자: (떨리는 목소리로) 이걸… 누가…
[상자 안 쪽지를 펼친다. 준호의 글씨]
쪽지(준호 목소리): "장모님, 혼자 아프지 마세요. 수술 날 제가 모시고 가겠습니다."

[95초]
영자: (준호를 바라보며) 자네가… 어떻게 알았어?
준호: 두 달 전에 장모님 아파트로 배송을 갔는데요. 계단에 혼자 앉아서 무릎을 붙잡고 계시더라고요.
준호: 말씀 안 하시길래… 그냥 모른 척했습니다.
성민: (작게, 고개를 숙이며) …저는 전혀 몰랐네요.

[106초 / 해소]
준호: 택배는 문 앞까지만 가지만, 가족은 문 안까지 들어가 봐야죠.
영자: (눈물을 훔치며) 내가… 내가 사람을 몰라봤네. 미안하네, 작은사위.
[영자가 상석의 방석을 들어 준호 쪽으로 내민다]
영자: 이리 와 앉게. 오늘부터 여기가 자네 자리야.

[116초]
수진: (눈물 섞인 웃음) 엄마, 갈비도 줘야지.
영자: (갈비를 준호 그릇에 가득 담으며) 그래, 많이 먹어. 우리… 작은사위.

[120초 / 엔딩 자막]
"이번 명절, 부모님 무릎 한 번 살펴보셨나요?"
"여러분 집에도 이런 사위 있나요?"
```

## 자가 점검
- [x] 첫 대사가 갈등인가? → "자네는 거기 앉지 말고 부엌 가서 전이나 부쳐"
- [x] 피해자에게 잘못이 없는가? → 준호는 끝까지 말없이 참고 예의를 지켜요
- [x] 복선이 40초 이전에 나오고 회수되는가? → 18초 절뚝이는 걸음과 준호의 시선, 30초 숨겨진 파스와 "계단 많이 다니셔?" → 70초 수술 예약 확인서
- [x] 반전 직전이 가장 심한 순간인가? → 선물을 발로 밀고 "창피해서 원"
- [x] 구원자가 한 명 이하인가? → 동료는 상자만 전달해요. 반전의 주인공은 준호 본인이에요
- [x] 결말이 사과와 해소로 끝나는가? → 장모가 사과하고 상석과 갈비를 내줘요
- [x] 110~125초인가? → 약 120초

## 작가 노트
- **아이러니:** 의사 사위는 장모의 병을 몰랐고, 택배기사 사위만 알았어요. "직업으로 사람을 판단하지 마라"는 메시지를 대사로 설명하지 않고 상황으로 보여 줘요.
- **명대사:** "택배는 문 앞까지만 가지만, 가족은 문 안까지 들어가 봐야죠." 주인공의 직업을 그대로 교훈으로 바꾼 대사라 기억에 남아요.
- **반전의 전달 방식:** 택배 상자라는 소품이 제목("택배 상자에 대반전")과 반전을 동시에 맡아요. 썸네일은 상자 속 서류를 들고 굳은 장모의 얼굴이에요.
- **배경음악:** 0~70초는 단조 피아노, 70초 상자 개봉부터 장조 피아노와 현악기로 바꿔요. 58~70초와 106초 명대사에서 음악을 더 낮춰요.

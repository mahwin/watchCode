# 주제 검증

> 경로는 모두 **키트 폴더** 기준입니다. 저장소 전체를 열었다면 `orae-channel/`, 키트 폴더를 바로 열었다면 현재 폴더가 키트 폴더입니다. 도구 출력 파일(JSON)이 키트에 쌓이지 않도록 도구는 임시 폴더에서 실행하고 키트 경로를 붙여 부릅니다.

입력: 주제 하나 또는 여러 개. 없으면 `docs/08_주제백로그.md`의 '대기' 주제 5개를 검증한다.

1. `docs/03_포맷공식.md`의 '주제 선정 체크리스트'와 `docs/08_주제백로그.md`를 읽는다.
2. 스크래치 폴더에서 수요를 측정한다.
   - 음식: `python3 <키트>/tools/demand_scan.py <주제들>` (음료는 `--verb 마시면`)
   - 음식이 아닌 주제는 `--query "{} 검색어 틀"`을 쓰거나 `python3 <키트>/tools/yt.py videos "<검색어>"`로 직접 본다.
3. 주제마다 체크리스트 5개 항목을 0/1로 채점하고 근거를 한 줄씩 단다.
   - 4번(수요)은 측정값: 100만 회 넘은 건강 영상 수와 최고 조회수
   - 5번(겹침)은 `episodes/` 폴더 목록과 비교
4. 표로 보고한다: 주제 / 점수 / 수요 수치 / 추천 제목 형식 / 진행·보류 / 이유
5. 사용자가 원하면 `docs/08_주제백로그.md`에 결과를 반영한다.

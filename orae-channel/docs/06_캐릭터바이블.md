# 06. 캐릭터 바이블

## 0. 현재 상태
| 캐릭터 | 상태 |
|---|---|
| 오래 박사 (사슴) | 1차 생성 완료. 블레이저 어깨에 견장 같은 무늬가 생겨 **수정 프롬프트로 재생성 필요** |
| 50대 남성 주인공 | 프롬프트 준비, 생성 전 |

**변경 이력:** 처음에는 거북이 마스코트로 만들었으나 너무 귀여워 전문가 느낌이 부족해서 사슴으로 바꿨습니다. 레퍼런스의 말 마스코트는 일본어 말장난이라 따라 하지 않습니다.

## 1. 오래 박사 (마스코트, 내레이터의 얼굴)
| 항목 | 내용 |
|---|---|
| 정체 | 지혜롭고 믿음직한 중년 사슴 학자. TTS 목소리의 주인 |
| 상징 | 사슴은 십장생(장수)이고, 사슴 '록(鹿)'은 재물을 뜻하는 '록(祿)'과 소리가 같아 **건강과 재물**을 함께 상징합니다 |
| 이름 | '오래 박사'. 장수(건강)와 오래 모으기(장기투자). '박사'는 별명이며 실제 자격을 내세우지 않습니다 |
| 성격 | 차분, 다정, 과장을 싫어함, 근거 확인을 좋아함 |
| 고정 요소 | 연갈색 털(#B57F50), 크림색 주둥이·가슴(#F3E3C7), 좌우 대칭 뿔(양쪽 3갈래), 얇은 동그란 금테 안경, 남색 블레이저(#1F3A5F) + 흰 행커치프 + 흰 셔츠 + 빨간 넥타이(#E0302F), 약 3.5등신 |
| 절대 넣지 않음 | 흰 가운, 청진기, 의료 십자가, 녹용 약재, 견장·어깨 패치, 털 무늬(옷 위에 그려짐) |
| 시그니처 멘트 | "오늘 배운 잡학으로, 오래오래 건강하게. 오래 박사였습니다." |

**표정과 쓰임:** 차분한 미소(아이콘, 엔딩, 번호 카드) / 놀람(썸네일 결과 장면) / 검지 세운 경고(하면 안 되는 습관) / 턱 괴고 생각(질문형 전환) / 윙크 엄지척(정답 공개, 정리 카드)

## 2. 50대 남성 주인공
- 평범하고 친근한 50대 초반 한국 남성, 보통 키, 배가 살짝 나온 통통한 체형
- 짧은 흑발에 옆머리 희끗, 잔주름 있는 온화한 눈, 면도한 얼굴
- 청회색 반팔 라운드 티(#4F6D8A), 베이지 면바지, 갈색 캐주얼화
- 약 5.5등신. 실존 인물을 닮지 않은 오리지널
- 옷 색은 제품에 맞춰 바꿔도 되지만 얼굴과 머리는 고정

## 3. 50대 여성 주인공
- 따뜻하고 친근한 50대 초반 한국 여성, 보통 체형
- 어깨 길이 짙은 갈색 단발에 흰머리 몇 가닥, 웃음 주름, 옅은 화장
- 세이지그린 니트 카디건(#7C9A6E), 크림색 라운드 상의, 베이지 슬랙스, 플랫슈즈
- 약 5.5등신. 갱년기, 피부, 변비, 골다공증 같은 여성 주제에서 주인공

## 5. 얼굴을 매번 똑같이 유지하는 방법
1. 시트에서 마음에 드는 1장을 정하고 `assets/characters/`에 저장합니다. 시드값이 있으면 기록합니다.
2. 이후 모든 생성에 **그 이미지를 참조로 첨부**합니다.
3. 색상 코드와 '넣지 않을 것' 문장을 매번 프롬프트에 넣습니다.
4. 자주 쓰는 표정과 포즈 20장 정도를 미리 만들어 배경을 지운 PNG로 저장하고 돌려 씁니다. 영상마다 새로 만들면 얼굴이 조금씩 달라집니다.

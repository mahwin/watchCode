# EP002 「302호 어머님」

**제목:** 동창회에서 요양보호사 친구를 비웃은 사모님… 걸려온 영상통화 한 통에 대반전
**로그라인:** 동창회에서 요양보호사 정숙을 비웃던 부잣집 동창 미숙이 정숙의 휴대폰을 빼앗아 영상통화를 받는다. 화면 속 사람은 3년째 찾아가지 않은 미숙의 친어머니였고, 그 어머니를 매일 돌보던 사람이 바로 정숙이었다.
**선정 이유:** 후보 8개 중 최고점(24/25, `episodes/backlog.json`). 레퍼런스 최고 히트 소재인 "동창회 무시"(620만)를 쓰되, 반전을 **가해자 자신의 잘못(부모 방치)**으로 만들어 1편(은인 반전)과 구조가 겹치지 않아요.

[0초 / 중식당 룸, 원형 테이블. 정숙이 늦게 들어와 앉는다]
미숙: 어머, 정숙아. 너 아직도 남의 집 노인네 기저귀 갈고 다니니?
정숙: (웃으며) 응. 요양보호사 일 해.

[8초]
미숙: 그 나이에 창피하지도 않니? 손 꼴 좀 봐.
경자: (어색하게 웃으며) 미숙아, 오랜만에 만났는데…
미숙: 왜, 내가 틀린 말 했어?

[18초 / 복선 ①]
미숙: 우리 엄마는 한 달에 오백짜리 요양원에 계셔. 햇살요양원이라고, 들어는 봤니?
정숙: (손을 멈추고, 미숙을 잠깐 바라본다) …햇살요양원?
미숙: 왜, 너 같은 사람은 들어가 보지도 못하는 데야.

[30초 / 복선 ②]
정숙: 나 오늘 일찍 가 봐야 해. 어르신 한 분이 오늘 생신이셔.
미숙: 생신? (웃음) 남의 부모 생일은 잘도 챙기네.

[40초]
미숙: (지갑에서 오만 원을 꺼내 테이블에 툭) 회비 부담되지? 이걸로 내.
정숙: 괜찮아. 회비는 이미 냈어.
경자: 미숙아, 그만해. 좀 심하다.

[52초 / 최고 긴장]
[정숙의 휴대폰이 진동한다. 화면에 '302호 어머님 영상통화']

정숙: 미숙아, 그거 줘. 급한 전화야.
미숙: 302호 어머님? (웃음) 노인네가 뭐가 급해. 내가 대신 받아 줄게.
[미숙이 스피커로 영상통화를 받는다] [툭]

[68초 / 반전]
순례(화면): 정숙아… 우리 정숙이니?
미숙: (얼굴이 굳는다) …엄마?  [헉]
순례(화면): 오늘 동창회 간다더니… 혹시 우리 미숙이도 만났니?
순례(화면): 바빠서 3년째 못 온다고… 보고 싶다고 좀 전해 줘.

[85초]
미숙: (손이 떨린다) 엄마… 왜 정숙이한테…

[98초 / 해소]

정숙: 부끄러운 건 남의 부모 기저귀 가는 게 아니야. 내 부모를 잊고 사는 거지.

[110초]

[118초 / 엔딩 자막]

## 자가 점검 (02_script.md)
- [x] 첫 대사가 갈등인가? → "남의 집 노인네 기저귀 갈고 다니니?"
- [x] 피해자에게 잘못이 없는가? → 정숙은 회비도 냈고 끝까지 예의를 지켜요
- [x] 복선이 40초 이전에 나오고 반전에서 회수되는가? → 18초 "햇살요양원"과 정숙의 멈칫, 30초 "어르신 생신" → 68초 영상통화, 112초 "오늘 어머님 생신"
- [x] 반전 직전이 가장 심한 순간인가? → 휴대폰을 빼앗아 비웃으며 스피커로 받음
- [x] 구원자가 한 명 이하인가? → 구원자 없이, 가해자 자신이 받은 전화로 드러나요
- [x] 결말이 사과와 해소로 끝나는가? → 사과하고 함께 어머니를 찾아가요 (어머니는 살아 계시고 웃으며 끝나요)
- [x] 110~125초인가? → 약 120초

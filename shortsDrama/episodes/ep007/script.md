# EP007 「1번 통장」

**제목:** VIP 창구에서 할아버지를 쫓아낸 은행 직원… 바닥에 떨어진 낡은 통장 하나에 대반전 #시니어드라마 #시니어쇼츠 #시니어 #반전드라마
**로그라인:** 은행 VIP 창구 직원이 허름한 할아버지를 쫓아내고 낡은 종이 통장을 발로 밀어낸다. 지점장이 주운 그 통장은 50년 전 이 지점의 1번 계좌였고, 할아버지는 평생 모은 돈을 장학금으로 내놓으러 온 길이었다. 그리고 그 장학금을 받았던 학생 중 한 명이 바로 그 직원이었다.
**레퍼런스 중복 확인:** 레퍼런스 238편 제목에 은행·통장 소재는 없어요.
**반전 유형:** 정체 반전(1번 고객) + 가해자가 수혜자였다는 2차 반전
**길이:** 약 120초

## 등장인물
| id | 이름 | 역할 | 설명 |
|---|---|---|---|
| C1 | 춘식 (82) | 피해자 | 낡은 점퍼, 보자기에 싼 종이 통장. 말이 느리고 점잖아요 |
| C2 | 박서연 (32) | 가해자 | VIP 창구 직원. 명찰 '박서연' |
| C3 | 사모님 (60대) | 조연 악역 | VIP 고객. 옆에서 비웃어요 |
| C4 | 지점장 (50대) | 반전 전달 | |

**복선 소품:** 로비 벽의 액자 '개점 50주년 - 첫 번째 고객님께 감사드립니다'(젊은 시절 춘식의 흑백 사진), 서연의 명찰

## 나레이션 (대사만)
```
[0초]
서연: 할아버지, 여기 VIP 창구예요. 번호표 뽑고 저쪽 가서 기다리세요.
춘식: 통장 정리 좀 하려고… 이것 좀 봐 줘요.

[8초]
서연: (웃음) 이런 종이 통장 요즘 누가 써요? 저기 기계 가서 하세요.
사모님: 아유, 냄새. 여기 VIP 자리 맞아요?

[18초 / 복선: 춘식이 로비의 '첫 번째 고객' 액자를 바라본다]
춘식: 기계는 내가 잘 몰라서… 그리고 오늘은 큰돈을 좀 옮기려고 왔어요.
서연: 큰돈이요? 얼마요, 삼십만 원?

[30초 / 복선: 춘식이 서연의 명찰 '박서연'을 보고 잠시 멈칫한다]
춘식: …박서연.
서연: 왜요? 제 이름은 왜 보세요? 불쾌하게.

[40초]
서연: 청원경찰님! 이 어르신 좀 밖으로 모셔 주세요. 업무 방해예요.
춘식: 잠깐만요, 이 통장만 좀…
[통장이 바닥에 떨어진다]

[52초 / 최고 긴장]
서연: (통장을 발로 밀어내며) 보이스피싱 당하신 거 아니에요? 큰돈은 무슨.
사모님: (웃음) 은행도 손님을 가려 받아야지.

[62초 / 반전]
[2층에서 내려오던 지점장이 통장을 주워 펼친다]
지점장: 계좌번호… 001-000001… 1975년 개설…
지점장: (액자와 춘식을 번갈아 보며) 선생님… 우리 지점 첫 번째 고객님이시죠?
서연: …네?  [헉]

[75초]
춘식: 오늘은 이 통장, 마지막으로 정리하러 왔어요.
춘식: 50년 동안 모은 거, 전부 동네 아이들 장학금으로 보내려고요.
지점장: (잔액을 보고 놀라며) 선생님… 이걸 전부요?

[88초 / 2차 반전]
춘식: (서연을 바라보며, 조용히) 학생, 2010년에 우리 장학금 받았던 박서연 학생 맞지?
춘식: 그때 꿈이 은행원이라고 했었는데… 꿈은 이뤘네.
서연: (얼굴이 하얗게 질린다) 그럼… 그 장학금이…  [헉]

[100초 / 해소]
서연: (무릎을 꿇고 통장을 주워 소매로 닦으며) 할아버지… 죄송합니다. 정말 죄송합니다.
춘식: 창구는 사람 등급을 나누는 데가 아니라, 사람을 맞이하는 데예요.
춘식: 그 장학금은 학생 같은 아이가 또 받게 될 거예요. 이번엔 잘 맞이해 줘요.

[112초]
춘식: (통장을 서연에게 건네며 웃는다) 마지막 통장 정리는… 학생이 해 줘요.
서연: (울면서) 네… 제가 하겠습니다.

[120초 / 엔딩 자막]
"여러분은 은행에서 이런 대접 받아 보신 적 있나요?"
```

## 자가 점검
- [x] 첫 대사가 갈등인가? → "번호표 뽑고 저쪽 가서 기다리세요"
- [x] 피해자에게 잘못이 없는가? → 통장 정리를 부탁했을 뿐이에요
- [x] 복선이 40초 이전에 나오고 회수되는가? → 18초 '첫 번째 고객' 액자 → 62초 1번 계좌 / 30초 명찰을 보고 멈칫 → 88초 장학생
- [x] 반전 직전이 가장 심한 순간인가? → 통장을 발로 밀어내며 "보이스피싱 당하신 거 아니에요?"
- [x] 구원자가 한 명 이하인가? → 지점장은 통장을 주워 읽을 뿐이고, 2차 반전은 할아버지 본인이 터뜨려요
- [x] 결말이 사과와 해소로 끝나는가? → 사과, 마지막 통장 정리를 맡김
- [x] 3분 이내인가? → 약 120초

## 작가 노트
- **2차 반전이 핵심이에요.** "알고 보니 1번 고객"까지는 예상하는 시청자도, "무시한 직원이 그 장학금을 받은 학생"에서 한 번 더 놀라요. 레퍼런스에는 없는 구조예요.
- **복선:** 30초에 할아버지가 명찰을 보고 이름을 중얼거려요. 직원은 "불쾌하게"라고 하지만, 다시 보는 시청자는 "그때 알아봤구나" 하게 돼요.
- **엔딩:** 무시당한 통장을 무시한 사람이 마지막으로 정리하게 해요. 벌 대신 기회를 주는 결말이라 시니어 시청층의 품위 있는 해소 취향에 맞아요.
- **배경음악:** 0~62초 단조 피아노, 62초 지점장 등장부터 장조. 52~62초와 88~100초에서 음악을 3~6dB 더 낮춰요.

# 03. 포맷 공식: 주제, 제목, 썸네일, 구성

레퍼런스 분석(02)과 한국 수요 측정(08)에서 뽑은 우리 채널의 제작 공식입니다. **새 에피소드는 이 문서를 기준으로 만듭니다.**

## 1. 주제 선정 체크리스트
5개 중 **4개 이상**이면 진행합니다. 점수는 `00_기획.md`에 기록합니다.
1. 4060의 절반 이상이 **이미 매일** 먹거나 마시거나 하는 것인가? (습관 = 시청자 정체성)
2. 마트·편의점 **제품**이나 눈에 보이는 사물로 썸네일에 보여줄 수 있는가?
3. **치매·혈관·혈당·간·장·관절·수면** 중 하나와 연결되는 연구가 있는가?
4. 한국 YouTube에 **100만 회 넘은 건강 영상**이 이미 있는가? (`tools/demand_scan.py`로 확인)
5. 우리 채널에서 **최근 10편 안에 다룬 소재와 겹치지 않는가?**

**피할 주제:** "A에 B를 섞으면" 같은 조합 레시피, 특수 재료(젤라틴, 시나몬 등), 기적 같은 주장, 같은 소재 재탕, 근거가 약한데 공포만 큰 주제

**경제 편 주제 기준:** 제도·계산·함정(국민연금 수령 시기, 은퇴 후 건보료, 연금저축·IRP, 간병비, 실손보험). 종목·코인은 다루지 않습니다.

## 2. 제목 공식
**기본형 (레퍼런스 번안)**
- `매일 [음식] [먹는/마시는] 사람, 몸에서 ○○가 바뀝니다 | [부제] [채널명] 키워드/키워드/키워드`

**한국에서 검증된 형식 (실제 조회수)**
| 형식 | 예시 | 실제 사례 |
|---|---|---|
| 기간 실험형 | [기간] 동안 매일 ○○ 먹으면 일어나는 일 | 지식인사이드 "7일 동안 당근을 '이렇게' 먹었더니" 486만 |
| 일어나는 일형 | 한 달간 ○○를 매일 먹으면 일어나는 일 | 사과 편 246만 |
| 안 되는 사람형 | ○○ 먹으면 안 되는 사람 | 고구마 편 367만 |
| 손해 회피형 | ○○, 이렇게 먹으면 오히려 독 | 냉동 블루베리 211만 |
| 비교 측정형 | A vs B, ○○ 비교 | 생로병사 "블랙커피 vs 믹스커피 혈당" 543만 |

**규칙**
- 제목 앞 20자 안에 음식명과 핵심 호기심이 들어가야 합니다.
- 숨긴 ○○의 답은 **본문 2분 안에 분명히** 말합니다. 낚시 느낌을 남기지 않습니다.
- 금지: "거의 전원", "100%", "완치", "약 끊어도", "의사들이 숨긴" 같은 단정·음모형 표현
- 끝에 키워드 3개(질병/부위/대상)를 붙입니다. 예: `간/혈당/커피믹스`
- 같은 영상에 제목 3개를 준비하고 YouTube Studio **A/B 테스트**(최대 3개, 시청시간 기준 승자)로 고릅니다.

## 3. 썸네일 공식 (1280×720)
```
┌──────────────────────────────────────────────┐
│  1줄: 매일 [음식(빨강)] 마시는 사람              │  ← 위쪽 30%
│  2줄: 몸에서 [ ? (빨간 박스) ]가 바뀝니다        │
├──────────────────────────────────────────────┤
│ [제품]  [주인공이 먹는 장면] ➡ [놀란 주인공][오래 박사] │  ← 아래 70%
└──────────────────────────────────────────────┘
```
- 배경 흰색, 글씨는 아주 굵은 검정 고딕, 강조색은 빨강(#E0302F) 하나만 씁니다.
- 글자는 두 줄, 줄당 10자 안팎. 4060은 노안이 있으니 해외 채널보다 더 크고 적게 씁니다.
- 제품은 **실존 브랜드 없이 일반 포장**으로 그립니다.
- 주인공 옷 색을 제품 색에 맞춰도 됩니다(토마토 편 빨간 셔츠). 얼굴과 머리는 절대 바꾸지 않습니다.
- 오래 박사는 결과 장면에서 놀라거나 걱정하는 표정으로 주인공 옆에 섭니다. 크기는 주인공의 70~80%.
- 여성 관심 주제(갱년기, 피부, 변비 등)는 여성 주인공을 씁니다. 애매하면 남녀 2안을 만들어 A/B 테스트합니다.
- 이미지 생성 프롬프트 틀은 `06_캐릭터바이블.md`의 '썸네일 장면 틀'을 씁니다. 글자는 생성 후 편집 도구로 얹습니다.

## 4. 영상 구성 템플릿 (목표 14~17분)
| 시간 | 구간 | 핵심 |
|---|---|---|
| 0:00 | **훅** (60초 안팎) | 시청자 상황 맞히기 → 상식 뒤집기 → 최신 연구 예고 → 경고 → 목차. **가장 궁금한 것 하나는 예고만** |
| 1:00 | 기초 (20~30초) | 쉬운 말로 무엇인지, 핵심 성분 하나 |
| 1:30 | **제목의 답 공개** + 효과 N가지 (4~6개) | "결론부터 말하면 ○○다." 항목당 40~60초, 항목 공식은 04 문서 |
| 6:30 | **다시 붙잡기** + 하면 안 되는 습관 3가지 | "여기까지 들으면 ~하고 싶어졌겠지만…". **가장 몰랐을 정보를 여기에** |
| 10:00 | 고르는 법 2~3가지 | 마트·편의점 실제 상황, 영양성분표 '한 병 전체' 계산 |
| 12:00 | 함께 먹으면 좋은 것 2~3가지 | 앞 내용 다시 불러오기 |
| 13:30 | **마지막 공개** | 훅에서 예고한 내용 (예: 먹는 시간) |
| 14:30 | 마무리 (30초) | 3줄 요약 → 댓글 질문 → 구독 요청 → 시그니처 멘트 |

**끝까지 보게 만드는 장치 (최소 3개 넣기)**
1. 훅에서 예고하고 마지막에 공개하는 '열린 고리' 1개
2. 중간(7~8분)에 공개하는 두 번째 고리 (예: "믹스커피는 괜찮을까?")
3. 약 3분마다 작은 정답이나 의외의 사실
4. 번호 매기기와 화면 번호 카드 (시청자가 길을 찾게)
5. 앞 내용 다시 불러오기 ("앞에서 본 '블랙'을 기억하자")

## 5. 업로드 운영
- 주 2~3편. 양보다 질. 같은 소재는 최소 10편 간격
- 설명란 순서: 두 줄 요약 → 챕터 → 참고 자료 → 안내 문구(면책, AI 음성, 제휴) → 해시태그 3개. 양식은 `templates/에피소드_패키지.md`
- 고정 댓글: 시청자 습관을 묻는 질문 1개 ("여러분은 커피를 어떻게 드시나요?")
- 챕터: 넣는 걸 기본으로 합니다. 시청자가 정답을 찾으러 건너뛰는 건 막을 수 없으니, 대신 정답을 3분마다 나눠 줍니다.
- 반응 좋은 옛 영상은 썸네일을 새 스타일로 교체하고, 6개월 뒤 '재방송'을 검토합니다.

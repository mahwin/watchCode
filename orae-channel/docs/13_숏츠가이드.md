# 13. 숏츠 가이드

숏츠의 역할은 **구독자 모으기**입니다(`12_수익화전략.md`). 롱폼 1편에서 잡학 하나씩 뽑아 매일 1개 올리고, 원본 롱폼으로 연결합니다.

**읽는 법**
1. **"의사들이 먹는 음식 3가지" 같은 일반 건강 숏츠는 포화 상태입니다.** 수백 편을 올린 채널들도 최근 중간값은 2천~3.7만 회입니다. 예전 히트작(200~400만 회)이 있어도 최근 작품은 거의 안 퍼집니다.
2. **잘 되는 두 갈래:**
   - **분명한 캐릭터 콘셉트:** 사물의 참견은 57편뿐인데 중간값 13.5만 회입니다.
   - **5060의 실생활 돈·행정 꿀팁:** 꿀팁한상(퇴사 후 건보료·연금), 100세연구소(통장)는 꾸준히 수만~수십만 회가 나옵니다.
3. 그래서 우리 숏츠는 **오래 박사와 부부 캐릭터가 나오는 생활 잡학 + 숫자로 보여 주는 실생활 정보**가 중심입니다. 경제 숏츠는 1단계부터 조금씩 시험합니다.

## 1-2. 알아 둘 규칙 변화
- **조회수 세는 법이 바뀌었습니다.** 2025년 3월부터 숏츠는 재생이 시작되기만 하면 조회수 1회로 셉니다. 2026년 8월 24일부터는 모든 형식에서 첫 화면이 재생되는 순간 셉니다. **수익과 수익 창출 기준은 '실제로 본 조회수(참여 조회수, 자격 조회수)'로 따로 셉니다.** 겉으로 보이는 조회수보다 스튜디오의 참여 조회수와 구독자 증가를 봅니다. ✅ [Search Engine Journal](https://www.searchenginejournal.com/youtube-changes-shorts-view-counts-no-change-to-monetization/543005/) ⚠️ 2026년 변경은 보도 기준
- **'관련 동영상' 연결은 2023년 8월에 생긴 기능**으로, 숏츠 설명란·댓글 링크가 막히면서 대신 생겼습니다. 같은 채널의 영상만 연결할 수 있습니다. ✅ [Search Engine Journal](https://www.searchenginejournal.com/youtube-adds-shorts-links-limits-links-elsewhere/495463)
- **'조회함 vs 스와이프' 비율**이 숏츠의 첫 관문입니다. 정해진 합격선은 없고 **내 채널의 이전 숏츠와 비교**합니다. 위치는 스튜디오 분석의 콘텐츠 → Shorts(메뉴 이름은 바뀔 수 있음).
- 50·60대의 숏츠 이용률을 연령별로 직접 밝힌 최근 자료는 찾지 못했습니다(2026-10-19 검색).

## 2. 규격
- 세로 9:16, 1080×1920. 길이 **30~50초** (짧을수록 끝까지 보게 하기 쉬움)
- **첫 화면이 썸네일입니다.** 위쪽 1/3에 큰 자막 2~3줄(줄당 8~12자, 흰색·노랑 + 검은 테두리, 핵심 단어만 빨강), 가운데 캐릭터 + 사물
- **가리는 곳 피하기:** 오른쪽 약 15%(좋아요·댓글 버튼)와 아래쪽 약 20%(제목·채널명)에는 중요한 글자를 두지 않음
- 자막은 화면 가운데~아래 사이, 한 번에 한 줄. 자동 자막은 꼭 고침
- 목소리는 롱폼과 같은 TTS 목소리, 배경음악은 작게

## 3. 구성 (40초 예시)
| 시간 | 내용 | 화면 |
|---|---|---|
| 0~2초 | **질문 훅** ("믹스커피, 하루 몇 봉까지 괜찮을까?") | 큰 자막 + 오래 박사 놀람·생각 낱장 |
| 2~8초 | 흔한 생각 ("한두 봉은 괜찮겠지?") | 남편 캐릭터가 믹스커피 타는 장면 |
| 8~30초 | **답** (숫자 하나 또는 3가지 목록). 출처는 화면 아래쪽 위에 작게 | 숫자 카드, 계산 카드 |
| 30~37초 | 한 줄 정리. 마지막 문장이 첫 질문으로 자연스럽게 이어지게 (다시 보기 유도) | 정리 카드 + 오래 박사 엄지척 |
| 37~40초 | "자세한 판정은 아래 영상에서" | 관련 동영상 연결 |

## 5. 올릴 때
- **제목:** 훅 질문 그대로 (예: `믹스커피, 하루 몇 봉까지 괜찮을까?`). '#shorts'는 넣지 않아도 됨
- **설명:** 한두 줄 요약 + 출처 1~2개 + "AI 음성으로 제작, 대본은 직접 작성·검수"
- **해시태그 2~3개:** 주제어 + #건강정보 + #후반전잡학
- **관련 동영상:** 업로드 화면의 '관련 동영상'에 원본 롱폼 선택 (숏츠 화면에 링크가 뜸)
- 사실적인 AI 음성이면 '변경된 콘텐츠: 예'
- 매일 같은 시간대에 1개

## 5-0. 원칙: 롱폼의 '요약'이 아니라 '핵심 하나'
- 숏츠는 **롱폼과 같은 주제·같은 캐릭터**로 만들되, **구성과 말투는 숏츠 전용**으로 완전히 새로 씁니다(아래 5-0-1). 명언, 음악, 유머, 일반 상식(지구과학 등)처럼 전혀 다른 숏츠는 다른 시청자를 데려와 롱폼으로 이어지지 않습니다. 일반 '잡학 상식' 숏츠는 수요도 약했습니다(최고 89만, 대부분 6만 이하).
- 다만 **15분을 40초로 줄인 요약본은 실패합니다.** 숏츠 하나에 질문 하나, 답 하나만 담고 그 안에서 완결합니다.
- 답을 숨기고 "자세한 건 영상에서"로만 끝내지 않습니다. **답을 먼저 주고**, 더 궁금한 사람을 롱폼으로 보냅니다.
- 비율 제안: 롱폼에서 뽑은 숏츠 80%, 숏츠 전용 20%. 숏츠 전용은 채널 주제 안의 시즌·시사 꿀팁(독감 접종, 연말정산 의료비 등)으로 하고, 반응이 좋으면 롱폼 주제로 올립니다(주제 시험장).

| 예 | 판단 |
|---|---|
| "커피 편 15분 요약: 혈당, 뱃살, 심장, 잠, 콜드브루…" | ❌ 너무 많음 |
| "콜드브루 한 병, 카페인 얼마일까?" → 평균 147mg, 제품마다 20배 차이 → 병 뒤 '고카페인' 표시 읽는 법 → "두 사람의 하루 커피 영수증은 관련 영상에서" | ✅ |
| "믹스커피 원재료, 맨 앞에 적힌 건?" → 설탕 → 많이 든 순서로 적기 때문 | ✅ |


## 5-0-1. 롱폼에서 숏츠 뽑는 법: 재료는 같고, 구성과 말투는 완전히 다르게
롱폼 영상을 잘라 쓰지 않습니다. **롱폼 조사에서 '재료(사실 하나)'만 가져와 숏츠용으로 새로 씁니다.**

**1단계: 재료 고르기 (롱폼 대본이 확정되면 5~8개 뽑기)**
| 기준 | 질문 |
|---|---|
| 숫자 하나 | 숫자 하나로 끝나는가? (147mg, 설탕 6.6kg) |
| 의외성 | 들으면 "어? 정말?" 하는가? |
| 바로 행동 | 오늘 당장 바꿀 수 있는 게 있는가? (병 뒷면 보기, 한 봉 바꾸기) |
| 화면 하나 | 그림 한 장, 카드 한 장으로 보여 줄 수 있는가? |
| 근거 | 조사 칸에 ✅ 출처가 있는가? |

3개 이상 맞으면 숏츠 재료입니다. 롱폼의 결정적 반전(마지막 공개)은 **롱폼 공개 후 1~2주 동안 아껴 두고** 그 뒤에 숏츠로 씁니다.

**2단계: 다르게 쓰기**
| | 롱폼 | 숏츠 |
|---|---|---|
| 말투 | 내레이터가 이야기를 들려줌 | **오래 박사가 화면을 보고 직접 말을 거는** 짧은 대화체 ("이거 아셨어요?") |
| 구성 | 이야기 + 여러 연구 + 정리 | **질문 → 답 → 오늘 할 일** 3단 |
| 연구 | 연구 규모·연도까지 소개 | "국내 연구에서" 한마디, 자세한 출처는 화면 자막 |
| 숫자 | 여러 개 | **하나** |
| 화면 | 16:9 장면 그림 | 세로 전용 구도: 캐릭터 크게, 글자가 주인공 |
| 녹음 | 롱폼 TTS | **숏츠용으로 따로 녹음** (같은 목소리, 조금 빠르게) |
| 길이 | 14~17분 | 30~45초 |

**숏츠 원고 예시 (재료: 콜드브루 카페인)** — 숫자는 커피 편 조사에서 ✅ 확인된 뒤 사용
| 시간 | 오래 박사 대사 | 화면 |
|---|---|---|
| 0~2초 | "편의점 콜드브루 한 병, 카페인 얼마나 들었을까요?" | 위 자막 "콜드브루 한 병 = 카페인 ?mg", 생각하는 오래 박사 |
| 2~7초 | "커피 한 잔이니까 100쯤? 아닙니다." | 고개 젓는 오래 박사 |
| 7~20초 | "국내 연구에서 콜드브루 18종을 재 봤더니, 평균 147밀리그램. 제품에 따라 스무 배 넘게 달랐습니다." | 병 여러 개 그림 + 숫자 카드 "26~630mg", 작은 출처 자막 |
| 20~32초 | "병 뒤에 '고카페인 함유'라고 적혀 있으면, 100밀리리터에 15밀리그램이 넘는다는 뜻이에요. 다 마시기 전에 뒷면부터 보세요." | 병 뒷면 확대 그림(글자는 편집) |
| 32~38초 | "오늘 마신 그 한 병, 몇 밀리그램이었을까요?" (첫 질문으로 돌아가 다시 보기 유도) | 관련 동영상: 커피 편 |

## 5-1. 시리즈 (요일별로 돌려 가며)

| 시리즈 | 내용 | 예시 |
|---|---|---|
| **오래 박사의 3초 판정** | A vs B 판정 | 믹스커피 vs 아메리카노, 당이 적은 쪽은? |
| **몰라서 손해 보는 생활 숫자** | 영수증·계산 | 믹스 세 봉을 1년이면 설탕 몇 kg? |
| **이거 진짜예요?** | 오해 바로잡기 | 빈속 커피는 위에 나쁘다? |
| **3초 퀴즈** | 초성·사진 퀴즈 | ㄱㄱㅁ, 가을에 제일 달아지는 이것은? |
| **후반전 돈 꿀팁** (시험) | 제도·행정 | 퇴직 후 건보료, 이것 모르면 더 냅니다 |

화면 배치(자막 위치, 캐릭터 자리, 출처 자막)는 틀로 고정하되, **문장과 장면은 매번 새로** 만듭니다.

## 6. 숏츠 제작 지시문 (서브에이전트용)
```
너는 유튜브 채널 '후반전 잡학'의 숏츠 담당이다. 첨부한 롱폼 제작서(또는 대본)와 이 가이드(13_숏츠가이드)만 보고 작업한다.
1) 롱폼에서 숏츠로 만들 잡학 3개를 고른다. 각각 근거와 출처가 롱폼 조사 칸에 있는 것만 고른다.
2) 롱폼 영상을 잘라 쓰지 않는다. 가이드 5-0-1의 2단계 표처럼 구성(질문 → 답 → 오늘 할 일)과 말투(오래 박사가 직접 말을 거는 대화체)를 롱폼과 완전히 다르게 새로 쓴다. 롱폼의 마지막 공개(결정적 반전)는 쓰지 않는다.
3) 숏츠마다 다음을 쓴다: 종류(대결형·목록형·돈 꿀팁형·퀴즈형·오해 바로잡기), 첫 화면 자막 2~3줄, 40초 이내 내레이션(가이드 3장 구성), 장면별 화면 지시(쓸 캐릭터 낱장 파일명 포함), 출처 자막, 제목, 설명 2줄, 해시태그 3개.
4) "의사들이 매일 먹는", "~가 살아난다", "무조건" 같은 권위 빌리기와 단정 표현을 쓰지 않는다. 숏츠 3개의 문장과 구성이 서로 겹치지 않게 쓴다.
5) 결과를 마크다운으로 돌려줘라.
```

# 에피소드 검수

> 경로는 모두 **키트 폴더** 기준입니다. 저장소 전체를 열었다면 `orae-channel/`, 키트 폴더를 바로 열었다면 현재 폴더가 키트 폴더입니다. 도구 출력 파일(JSON)이 키트에 쌓이지 않도록 도구는 임시 폴더에서 실행하고 키트 경로를 붙여 부릅니다.

입력: 에피소드 폴더 (예: `episodes/002_계란`). 없으면 가장 최근 폴더.

1. `docs/07_규정체크리스트.md`, `docs/03_포맷공식.md`, `docs/04_내레이션가이드.md`를 읽는다.
2. 폴더의 모든 파일을 읽는다.
3. 점검한다.
   - **규정:** 07 문서 A의 체크리스트 전 항목. 위반 문장은 파일명과 문장을 그대로 인용한다.
   - **사실:** 대본의 모든 수치가 01_리서치.md에 출처와 함께 있는지. ⚠️ 자료가 결론을 떠받치고 있으면 표시한다. 필요하면 웹 검색으로 확인한다.
   - **표현:** 04 문서의 금지 표현, 단정 표현, 전문용어 미설명
   - **포맷:** 제목의 ○○ 답이 2분 안에 나오는지, 열린 고리 2개 이상, 번호 카드, 3분마다 작은 정답, 시그니처 멘트
   - **길이:** `python3 <키트>/tools/duration.py <03_TTS원고.txt>`로 14~17분인지
   - **이미지:** 04_이미지프롬프트.md에 브랜드 로고·글자 금지 문장, 의료인 연상 요소 없음
   - **업로드 정보:** 설명란 참고 자료, AI 음성 고지, 제휴 고지(해당 시)
4. `06_검수.md`에 결과를 쓴다: 항목별 통과/수정 필요, 수정 제안 문장, 남은 확인 사항.
5. 사용자에게 "바로 고칠 것"과 "직접 확인할 것"을 나눠 짧게 보고한다. 사용자가 원하면 수정까지 한다.

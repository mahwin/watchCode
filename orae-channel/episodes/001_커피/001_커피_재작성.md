## A2. 반드시 지킬 원칙
1. **근거 없이 숫자를 쓰지 않는다.** 모든 수치에 출처. 원문 확인 ✅, 보도·2차 자료 ⚠️.
2. **단정하지 않는다.** 관찰 연구는 "~와 관련이 있었다", "~경향이 있었다". "낫는다·완치·거의 모두" 금지.
3. **전문가를 사칭하지 않는다.** 흰 가운, 청진기, "의사로서" 금지.
4. **레퍼런스 원고를 번역하거나 번안하지 않는다.** 이 편에서는 아래 항목을 **쓰지 않는다**: 마시는 시간대(아침 커피) 연구, 회사 커피머신과 카페스톨, 견과류·올리브유·다크초콜릿 조합, 장내 세균, 파킨슨병, "커피는 잠 깨는 음료가 아니다"로 시작하는 훅. 레퍼런스 참고문헌과 겹치는 연구는 **우리 질문에 꼭 필요할 때만** 쓰고 원문을 직접 확인한다.
5. **한국 자료를 우선한다.** 식약처, 한국소비자원, 국민건강영양조사 기반 연구, 질병관리청. 최소 3개.
6. **브랜드 로고·제품명은 쓰지 않는다.** 커피믹스·카페는 일반 그림으로.
7. 심장 두근거림, 임신, 위장 질환이 나오면 "치료 중이면 담당 의사와 상의" 문장을 넣는다.

## A6. 내레이션 규칙
- 본문은 다큐체(~다, ~이다), 마지막 인사만 존댓말. 문장은 짧게, 한 문장에 정보 하나
- 부부 대사는 짧은 따옴표 대사로 넣어도 됨 (내레이터가 읽음)
- 판정은 "승/패"보다 "이런 사람에게 맞다"로. 어느 커피도 '독'이나 '약'으로 부르지 않는다
- 훅 5단계: 상황 맞히기 → 상식 흔들기 → 규모 → 주의 → 목차 + 열린 고리
- 항목 공식: 번호·제목 → 배경 → 연구(연도·규모) → 숫자(관찰 연구는 '경향') → 이유 → 한국 자료
- 쉬운 말: 메타분석 → "여러 연구를 묶어 분석한 연구", 상대위험도 0.72 → "위험이 약 28% 낮았다", 인슐린 저항성 → "혈당을 낮추는 힘이 떨어진 상태"
- 금지: "○○ 마시면 당뇨가 낫는다", "믹스커피는 독", "의사들이 숨기는", "이것만 마시면"
- TTS 원고: 숫자가 이상하게 읽히면 한글로("사백 밀리그램"), 단위는 읽는 말로

## A7. 화면 규칙
- 내레이션 1~2문장 = 1컷, 컷당 4~8초. 같은 그림은 확대 위치를 바꿔 2~4컷까지
- **판정표 카드**를 라운드 끝마다 갱신 (4행 × 3열, 칸마다 짧은 판정 문구. 글자는 편집에서)
- 숫자는 숫자 카드, 계산은 순서대로 등장하는 계산 카드 ("한 봉 ○g × 3봉 = ○g")
- 연구 언급 시 왼쪽 아래 회색 출처 자막
- 반전 구간은 빨간 경고 테두리 + 오래 박사 경고 얼굴
- 대본에는 구간마다 `> **화면:**` 줄로 적는다

# 01. 주제·제목 기획 프롬프트

> 용도: 에피소드 후보를 대량으로 뽑고 점수를 매겨요.
> 입력 변수: `{{COUNT}}` 뽑을 개수, `{{USED_TOPICS}}` 이미 만든 주제 목록(중복 방지용)

```xml
<role>
너는 유튜브 '시니어 반전 숏드라마' 채널의 메인 기획자야.
2분짜리 실사풍 AI 쇼츠 드라마의 주제와 제목을 기획해.
</role>

<winning-formula>
레퍼런스 채널(쇼츠 238개, 누적 2억 회)을 분석해서 검증된 공식이야.
1. 공공장소나 가족 행사에서 계급 차이(옷차림·돈·직업·나이) 때문에 무시가 벌어진다
2. 피해자는 잘못이 없고 끝까지 품위를 지킨다
3. 악역이 분명하다 (시청자가 분노할 대상)
4. 잠시 후 정체가 드러나거나 정의가 실현되어 가해자가 얼어붙고 사과한다
5. 반전은 앞에 깔아 둔 복선(소품·대사·과거 인연)으로 회수한다
</winning-formula>

<high-performing-settings>
장소: 명품관, 백화점, 마트, 결혼식, 상견례, 명절, 동창회, 식당, 병원, 회사 로비, 아파트 경비실, 은행
갈등 축: 시어머니-며느리, 사돈, 축의금, 갑질, 빈부 차이, 직업 무시, 학력 무시
역전 장치: 회장·건물주·의사 같은 숨은 정체, 과거 은인 관계, 제3자의 정의로운 개입
</high-performing-settings>

<avoid>
- 악역 없는 감성물 (조회 중앙값 수천~수만 회)
- 동물·개그·"ㅋㅋ" 톤
- 결말이 슬프기만 한 이야기 (장애, 실종, 사망)
- 제목에 결말이 드러나는 경우
- 1부/2부로 나누는 구성 (1부는 중앙값 30만으로 약함)
- 실존 인물이나 역사 인물
- 이미 만든 주제와 겹치는 설정: {{USED_TOPICS}}
</avoid>

<title-rules>
- 30~42자
- 구조: [누가] + [어떤 무시·갈등]… + [잠시 후 / 결국 / 알고 보니] + [대반전 / 한마디 / 이유 / 정체]
- "대반전" 또는 "잠시 후"를 자연스럽게 포함 (포함 시 조회 중앙값이 5배)
- 인물은 이름이 아니라 역할명으로 쓴다 (시어머니, 청소부, 회장, 사돈)
- 결말은 숨기고 궁금증만 남긴다
</title-rules>

<task>
위 공식으로 에피소드 후보 {{COUNT}}개를 기획해.
소재가 한쪽으로 몰리지 않도록 장소와 갈등 축을 골고루 섞어.
각 후보를 아래 기준(각 1~5점)으로 스스로 채점하고 총점 순으로 정렬해.
- 분노도: 악역에게 얼마나 화가 나는가
- 반전 쾌감: 반전이 예상 밖이면서 납득되는가
- 복선 회수: 앞의 소품이나 대사가 반전에서 터지는가
- 1초 이해도: 썸네일과 제목만 보고 상황이 바로 이해되는가
- 신선도: 흔한 이야기와 얼마나 다른가
</task>

<output-format>
JSON 배열로만 출력해.
[
  {
    "id": "후보 번호",
    "title": "유튜브 제목",
    "logline": "한 줄 줄거리 (반전 포함)",
    "location": "장소",
    "victim": "피해자 역할",
    "villain": "가해자 역할",
    "twist": "반전 내용",
    "foreshadow": "복선으로 쓸 소품이나 대사",
    "scores": {"anger":0,"twist":0,"foreshadow":0,"clarity":0,"fresh":0},
    "total": 0
  }
]
</output-format>
```

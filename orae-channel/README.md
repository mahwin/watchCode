# 후반전 잡학 채널 제작 키트

40~60대 한국인을 위한 **건강 + 경제 유튜브 채널** 제작 자료와 작업 도구입니다. 얼굴, 실제 전문가, 실제 목소리 없이 **캐릭터 일러스트 + AI 음성**으로 만드는 근거 중심 채널을 목표로 합니다.

## Claude Code에서 쓰는 법
Claude Code에 이렇게 말하면 됩니다.

| 하고 싶은 일 | 입력 예시 |
|---|---|
| 새 영상 패키지 만들기 | `/episode 계란` 또는 "계란 편 만들어줘" |
| 다른 형식으로 만들기 | `/episode 신호형 간`, `/episode 제도형 은퇴 후 건강보험료`, `/episode 퀴즈형 가을 제철 음식` |
| 주제가 될지 확인 | `/topic-check 고구마 사과 두부` |
| 업로드 전 검수 | `/episode-review episodes/002_계란` |
| 경쟁 채널 조사 | "tools/yt.py로 @채널핸들 조사해서 레퍼런스 분석처럼 정리해줘" |

명령이 안 보이면 `prompts/마스터_프롬프트.md`의 문장을 그대로 붙여 넣으세요.

## 도구 실행 예시
```bash
python3 tools/yt.py videos "매일 계란 먹으면"      # 조회수순 영상 검색
python3 tools/yt.py channel @ウマい健康雑学         # 채널 최신·인기 영상
python3 tools/yt.py video 7LSymhoLns8             # 설명란, 다시보기 구간, 댓글
python3 tools/demand_scan.py 계란 두부 토마토       # 주제 수요 측정
python3 tools/duration.py episodes/001_커피/03_TTS원고.txt   # 대본 길이
python3 tools/color_match.py 새그림.png                        # 오래 박사 색을 사람 캐릭터에 맞춤
python3 tools/cutout.py                                        # 캐릭터 시트를 낱장 투명 PNG로 자르기
```

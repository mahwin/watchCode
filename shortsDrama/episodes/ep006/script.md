# EP006 「혼주석」 (필살 소재 종합편)

**제목:** 국밥집 사돈을 맨 뒷자리로 보낸 시어머니… 잠시 후 비서가 "회장님" 부르자 대반전 #시니어드라마 #시니어쇼츠 #시니어 #반전드라마
**로그라인:** 손녀를 혼자 키운 시장 국밥집 할머니가 손녀의 결혼식에 온다. 신랑 어머니는 할머니를 혼주석에서 끌어내 맨 뒷자리로 보내고, "오늘 우리 아들 회사 회장님이 오시니 맨 앞자리는 비워 두라"고 자랑한다. 잠시 후 회장 비서가 들어와 할머니 앞에 고개를 숙인다.
**길이:** 약 125초

## 들어간 필살 소재 (레퍼런스 조회수 중앙값)
| 소재 | 레퍼런스 근거 |
|---|---|
| 정체 반전: 무시당한 사람이 알고 보니 회장 | 정체 반전 유형 중앙값 **180만** (전체 최고) |
| 회장 등장 | "회장" 키워드 중앙값 **180만** |
| 사돈 갈등 | "사돈" 키워드 중앙값 **170만** |
| 결혼식과 혼주석 | "혼주석을 요구한 친모"(300만), "결혼식 날 귓속말"(350만) |
| 겉모습으로 무시 (명품 vs 보자기) | "명품가방 할머니를 무시한 직원"(510만) |
| 제목의 "잠시 후 … 대반전" | 포함 시 중앙값 185만~210만 |

**레퍼런스와 다른 점:** 레퍼런스의 회장은 **밖에서 나타나 해결해 주는 사람**이에요. 여기서는 **무시당한 할머니 본인이 회장**이라, 구원자 없이 피해자가 직접 판을 뒤집어요. 복선 두 개로 반전을 미리 깔아 뒀어요.

## 등장인물
| id | 이름 | 역할 | 설명 |
|---|---|---|---|
| C1 | 말순 (78) | 피해자 → 회장 | 신부의 할머니. 시장에서 40년째 국밥을 팔아요. 사실은 그 국밥집에서 시작한 '말순식품' 창업 회장. 늘 수수한 차림에 낡은 보자기를 들고 다녀요 |
| C2 | 미자 (60) | 가해자 | 신랑 어머니. 명품 한복, 큰 반지. 아들이 '말순식품' 과장인 걸 자랑으로 삼아요 |
| C3 | 수아 (29) | 신부 | 할머니 손에 자랐어요. 할머니의 정체를 알지만, 할머니의 부탁으로 비밀로 했어요 |
| C4 | 준혁 (31) | 신랑 | 말순식품 과장. 할머니의 정체를 몰라요. 착하지만 엄마 앞에서 약해요 |
| C5 | 비서 (40대) | 반전 전달 | 회장 비서실장 |

**복선 소품:** 말순의 낡은 보자기 (한쪽 귀퉁이에 빛바랜 '말순국밥' 자수), 신랑 어머니의 "회장님은 얼굴을 안 드러내신대" 대사

## 대본

```
[0초 / 결혼식장 혼주석. 말순이 앞자리에 앉자 미자가 팔을 잡아끈다]
미자: 거기 아무나 앉는 자리 아니에요. 뒤로 가세요, 뒤로!
말순: (당황하며) 사돈… 나 신부 할미예요.

[8초]
미자: 알아요. 시장에서 국밥 판다는 그 할머니.
미자: 축의금이나 제대로 냈어요? 우리 쪽 하객들 보기 창피하니까 맨 뒤에 앉아요.
수아: (달려오며) 어머님, 우리 할머니예요! 혼주석에 앉으셔야죠.
미자: 수아야, 오늘 하루만 참아. 너 위해서 하는 말이야.

[22초 / 복선 ①]
미자: (휴대폰을 들고 자랑스럽게) 오늘 준혁이네 회사 회장님이 직접 오신대요.
미자: 회장님은 원래 얼굴을 절대 안 드러내신다는데, 우리 준혁이 결혼식엔 오신다잖아.
미자: (맨 앞자리를 가리키며) 그러니까 여긴 비워 둬요. 회장님 자리야.
[뒷자리로 가던 말순이 걸음을 멈추고, 아주 작게 웃는다]

[38초 / 복선 ②]
[말순이 낡은 보자기를 내민다. 귀퉁이에 빛바랜 '말순국밥' 자수]
말순: 사돈, 이거 우리 손녀 신혼집에 쓰라고 가져온 거예요.
미자: (손끝으로 집어 들며) 아유, 냄새. 국밥 국물 묻은 거 아니에요?
[미자가 보자기를 의자 밑으로 툭 던진다]

[50초]
준혁: 엄마, 그래도 이건 좀…
미자: 넌 가만있어. 너 오늘 회장님한테 잘 보여야 돼. 과장에서 끝날 거야?
수아: (보자기를 주워 털며, 떨리는 목소리로) 할머니, 죄송해요…
말순: (수아의 손을 토닥이며) 괜찮다. 우리 손녀 결혼하는 날인데 할미가 어디 앉은들 어떠냐.

[65초 / 최고 긴장]
미자: (하객들 들으라는 듯 큰 소리로) 솔직히 이 결혼, 우리 집이 많이 손해 보는 거예요.
미자: 국밥 팔아서 손녀 하나 키운 집에서 혼수를 뭘 해 오겠어요?
미자: 우리 준혁이 앞길 막지 않게, 할머니는 식 끝나면 조용히 먼저 가세요.

[78초 / 반전]
[식장 문이 열리고 정장 차림의 비서실장이 들어온다. 하객들이 웅성거린다]
미자: (벌떡 일어나 옷매무새를 고치며) 어머, 회장님 비서실장님! 회장님은 어디…
[비서실장이 미자를 지나쳐 맨 뒷자리로 걸어간다. 말순 앞에서 허리를 깊이 숙인다]
비서실장: 회장님, 여기 계셨습니까. 앞자리 준비해 두었습니다.
미자: …회, 회장님?  [헉]
준혁: (얼어붙는다) 할머님이… 우리 회사… 회장님이세요?

[93초]
말순: (천천히 일어나 보자기를 받아 들며) 이 보자기가 내 첫 가게 간판이었어요.
말순: 국밥 한 그릇 팔아서 시작한 회사가 지금 사돈 아드님이 다니는 그 회사고요.
미자: (손이 떨린다) 회장님… 저는 정말 몰라서…

[103초 / 해소]
말순: 모르셨으니까 그러신 거죠. 그래서 더 잘 알게 됐어요. 사돈이 어떤 분인지.
말순: 돈은 숨길 수 있어도, 사람 됨됨이는 못 숨기는 법이에요.
말순: 사과는 나 말고 우리 손녀한테 하세요. 오늘 제일 서러운 사람은 저 아이니까.
미자: (수아를 보며, 고개를 숙인다) 수아야… 미안하다. 내가 미안해.

[116초]
말순: (맨 앞 혼주석을 가리키며 웃는다) 회장님 자리는 맨 앞이라고 했죠?
말순: 그럼 오늘은 거기 앉을게요. 회장 말고, 신부 할미로.
[수아가 울면서 말순의 팔짱을 끼고 혼주석으로 걸어간다]

[125초 / 엔딩 자막]
"여러분이 할머니였다면, 이 사돈을 용서하시겠어요?"
```

## 자가 점검
- [x] 첫 대사가 갈등인가? → "거기 아무나 앉는 자리 아니에요. 뒤로 가세요!"
- [x] 피해자에게 잘못이 없는가? → 손녀 결혼식에 온 할머니. 끝까지 화내지 않아요
- [x] 복선이 40초 이전에 나오고 회수되는가? → 22초 "회장님은 얼굴을 안 드러내신대"와 말순의 작은 웃음, 38초 '말순국밥' 자수 보자기 → 78초 비서실장, 93초 "이 보자기가 내 첫 가게 간판"
- [x] 반전 직전이 가장 심한 순간인가? → 하객들 앞에서 "식 끝나면 조용히 먼저 가세요"
- [x] 구원자가 한 명 이하인가? → 비서는 정체만 드러내고, 판을 뒤집는 건 할머니 본인이에요
- [x] 결말이 사과와 해소로 끝나는가? → 신부에게 사과, 할머니가 혼주석으로
- [x] 3분 이내인가? → 약 125초

## 작가 노트
- **아이러니 3단:** ① 회장 자리를 비워 두라며 회장을 뒤로 보내요 ② 아들이 잘 보여야 할 회장을 엄마가 모욕해요 ③ 던져 버린 보자기가 회사의 첫 간판이었어요
- **시청자와의 두뇌 싸움:** 22초에 "회장님은 얼굴을 안 드러내신대"와 할머니의 작은 웃음이 나오면, 눈치 빠른 시청자는 "설마 할머니가?" 하고 끝까지 봐요. 그 예상이 맞아떨어지는 쾌감이 이 장르의 핵심이에요
- **엔딩 한 방:** "회장님 자리는 맨 앞이라고 했죠? 그럼 오늘은 거기 앉을게요. 회장 말고, 신부 할미로." 가해자의 대사를 그대로 돌려줘요
- **썸네일:** 비서실장이 허리를 숙이는 순간, 뒤에서 얼어붙은 신랑 어머니의 얼굴 클로즈업 + "…회, 회장님?"
- **배경음악:** 0~78초 단조 피아노, 78초 비서 등장부터 장조 피아노와 현악기. 65~78초와 103~110초(할머니 명대사)에서 음악을 3~6dB 더 낮춰요

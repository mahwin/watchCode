# 05. 화면 구성 가이드

> **주의:** 레퍼런스 영상의 실제 컷 길이와 카메라 무빙은 측정하지 못했습니다(클라우드에서 영상 다운로드 차단). 아래 수치는 썸네일·설명란·다시보기 데이터와 일반적인 설명형 영상 관행에 기반한 **제안값**입니다. 영상을 몇 편 만든 뒤 YouTube 스튜디오의 '시청 지속률' 그래프를 보고 조정합니다.

## 1. 제작 방식
- 정지 일러스트(캐릭터 + 소품 + 도표)에 **움직임과 자막**을 입히는 방식입니다. 레퍼런스도 일러스트 + TTS + Premiere/After Effects 편집입니다.
- 일러스트는 `06_캐릭터바이블.md`의 고정 캐릭터와 같은 화풍으로 만듭니다.
- 편집 도구: 캡컷, 프리미어 프로, 브루(Vrew) 등. 자동 자막은 반드시 사람이 고칩니다.

## 2. 컷 단위 규칙 (제안)
- **내레이션 1~2문장 = 1컷**, 컷 하나는 약 4~8초. 같은 그림을 10초 넘게 두지 않습니다.
- 숫자가 나오는 문장은 **숫자 카드** 컷으로 바꿉니다.
- 구간이 바뀔 때는 **번호 카드**(예: "2. 혈당")를 1~2초 넣습니다. 시청자가 길을 찾는 표지판입니다(다시보기 피크가 번호 시작점에 몰림).

## 3. 화면 요소 사전
| 요소 | 언제 | 모양 |
|---|---|---|
| 상황 컷 | 훅, 생활 장면 | 주인공이 먹거나 마시는 장면 |
| 번호 카드 | 항목 시작 | 흰 배경, 큰 번호 + 제목, 오래 박사 작은 포즈 |
| 장기 일러스트 | 간·장·혈관·뇌 설명 | 단순한 평면 일러스트, 변화는 2~3단계 그림으로 |
| 숫자 카드 | 연구 결과 | 큰 숫자 하나("-6%"), 아래 작은 설명 한 줄 |
| 비교 막대 | A vs B | 막대 2개, 차이가 나는 쪽만 빨강 |
| 출처 자막 | 연구 언급 시 | 화면 왼쪽 아래 작은 회색 글씨: "Carlström·Larsson, Nutrition Reviews 2018" |
| 경고 테두리 | 하면 안 되는 습관 | 화면 가장자리 빨간 테두리 + 오래 박사 경고 표정 |
| 계산 애니메이션 | 영양성분표, 돈 계산 | "100ml당 30kcal × 5 = 150kcal" 순서대로 등장 |
| 정리 카드 | 마무리 | 3줄 요약 + 오래 박사 엄지척 |
| 주의 자막 | 심장·약물 등 | "치료 중이라면 담당 의사와 상의하세요" 노란 박스 |

## 4. 움직임 (제안)
- 정지 그림에는 **천천히 확대(100% → 105~110%)** 를 기본으로 겁니다. 너무 빠르면 어지럽습니다.
- 숫자와 아이콘은 **톡 튀어나오는 등장**(0.2~0.3초)
- 화살표는 그려지듯 등장
- 전환은 단순하게(컷 또는 짧은 디졸브). 화려한 전환 효과는 쓰지 않습니다.
- 캐릭터 표정은 문장 내용에 맞춰 바꿉니다(놀람, 경고, 생각, 정답).

## 5. 자막 (제안)
- 고령 시청자용 자막 크기의 공식 기준은 찾지 못했습니다. 아래는 제안입니다.
- 화면 아래쪽, **최대 2줄**, 굵은 고딕, 흰 글씨 + 검은 테두리 또는 반투명 검은 띠
- 1080p 기준 글자 높이를 화면 높이의 약 5~6% 이상으로 크게 잡습니다.
- 핵심 단어 하나만 노랑 또는 빨강으로 강조합니다.
- 숫자는 아라비아 숫자로 씁니다(내레이션이 한글로 읽더라도).

## 6. 색상 팔레트
| 용도 | 색 |
|---|---|
| 강조 (썸네일·경고·넥타이) | 빨강 #E0302F |
| 기본 글씨 | 검정 #111111 |
| 배경 | 흰색 #FFFFFF, 크림 #FFF3D6 |
| 오래 박사 블레이저 / 넥타이 | 남색 #30435C / 빨강 #CF3A2F |
| 남성 주인공 티셔츠 | 청회색 #4F6D8A |
| 여성 주인공 카디건 | 세이지그린 #7C9A6E |
| 좋은 변화 표시 | 초록 #2E9E5B |

## 7. 화면 지시 쓰는 법 (대본용)
`02_제작대본.md`의 구간마다 `> **화면:**` 줄에 순서대로 적습니다. 예:
> **화면:** 번호 카드 '2. 혈당' → 커피잔이 1잔씩 늘 때마다 막대 '-6%' → 디카페인 컵 등장 '비슷' → '한국인 연구' 배지 → '블랙' 단어에 빨간 밑줄 / 출처: Carlström·Larsson, Nutrition Reviews 2018

이미지 생성이 필요한 장면은 `04_이미지프롬프트.md`에 장면 번호와 함께 프롬프트를 적습니다.

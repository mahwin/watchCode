# 훈작가 숏드라마 조회수 상위 10편 벤치마크

자료: 채널 쇼츠 238편 중 조회수 상위 10편. 대사는 자동 자막 8편으로 확인했고, 나머지 2편(0JJ5QEnTFW4, LoNsIXF5510)은 제목과 설명으로만 정리했어요.
주의: 구조만 참고하고, 대사는 그대로 쓰지 않아요.

## 2. 핵심 발견
1. **상위 10편 중 6편이 "선행 → 보답" 유형이에요.** 젊은이가 노인을 돕거나(2·6·7·8위), 노인이 젊은이의 됨됨이를 알아보고 보상해요(4·10위). 악역에게 참교육하는 이야기는 1·5위 정도뿐이에요. 우리가 지금까지 쓴 대본은 대부분 "악역 막말 → 참교육"이라, 가장 잘된 유형을 아직 거의 안 다뤘어요.
2. **좋아요율은 선행 이야기가 압도적이에요.** 3위 3.1%, 7위 3.0%, 6위 2.7%. 반면 무시·막장 계열은 0.9~1.8%예요. 조회수는 비슷해도 시청자가 "좋아하는" 이야기는 선행 쪽이에요.
3. **아주 단순해요.**
   - 장소 1~2곳, 인물 3~4명, **반전 1개**.
   - 대사량은 자막 기준 1,400~2,200자. 우리 대본(3,000자 안팎)보다 훨씬 적어요.
   - 회상, 복선 회수, 2차·3차 반전이 거의 없어요.
4. **악역이 약해요.** 계산원, 매장 직원, 운전기사처럼 잠깐 무례한 사람 정도예요. 분노보다 "착한 사람이 알아봐지는 쾌감"으로 끌고 가요.
5. **반전은 거의 다 "정체"예요.** 할머니가 이사장, 원장 어머니, 사장님 아들이 면접관, 회장. 시청자는 "착하게 살면 언젠가 보상받는다"를 확인하고 싶어 해요.
6. **보상이 구체적이에요.** 장학금(동생들까지), 인턴십, 병원비 대신 납부, 단골 약속, 며느리 제안. 돈이나 기회처럼 눈에 보이는 보상이에요.
7. **마지막에 교훈 한 줄을 직접 말해요.** "사람을 돈으로 안 보는 사람", "작은 배려 하나로도 누군가의 삶이 빛날 수 있답니다", "나는 기회 하나 줬을 뿐이에요".
8. **길이는 1분 45초~2분 16초**예요. 우리 목표 길이(1분 50초~2분)와 맞아요.

## 3. 상위작 공통 뼈대 (선행 → 보답형)
| 구간 | 내용 | 예시 |
|---|---|---|
| 0~15초 | 곤란한 노인(또는 실수한 청년) + 주변의 무례 | 계산대에서 돈이 모자란 할머니, 뒤에서 재촉하는 손님 |
| 15~45초 | 주인공의 조건 없는 선행 | "제 카드로 계산해 주세요", "괜찮습니다, 안 다치셨어요?" |
| 45~75초 | 보답을 거절하는 주인공, 주인공의 어려운 사정이 살짝 드러남 | "부모님은 안 계십니다", "휴학 중입니다" |
| 75~100초 | 정체 반전 | "이사장님, 차로 모시겠습니다" |
| 100~120초 | 구체적인 보상 + 교훈 한 줄 + 감사 | 장학금, 인턴, 병원비 |

## 4. 우리 채널에 적용할 것
- **선행 → 보답형을 주력 라인업에 추가해요.** 악역 참교육편과 번갈아 올려서 좋아요율을 끌어올려요.
- **반전은 1개로 줄여요.** 길어도 정체 반전 1개 + 보상 1개.
- **대사량을 2,000자 안팎으로 줄여요.** 한 장면에 대사 2~3줄.
- **보상은 눈에 보이게 해요.** 장학금, 일자리, 병원비, 집처럼 구체적인 것.
- **교훈 한 줄은 인물의 입으로 직접 말해요.**
- **베끼지 않아요.** 할머니 이사장, 면접관 아들, 원장 어머니 같은 설정은 이미 썼으니, 같은 구조에 다른 정체와 장소를 넣어요.

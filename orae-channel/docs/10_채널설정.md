# 10. 채널 설정

유튜브 채널을 만들 때 그대로 옮겨 쓰는 기본 정보입니다. 채널명은 2026-10-16에 확정했습니다.

## 1. 이름과 핸들
| 항목 | 값 |
|---|---|
| 채널명 | **후반전 잡학** |
| 핸들 (1순위) | `@후반전잡학` (핸들에는 띄어쓰기를 쓸 수 없습니다) |
| 핸들 (이미 있을 때) | `@후반전잡학TV`, `@후반전_잡학` |
| 마스코트 | 오래 박사 (사슴) |
| 프로필 사진 | `assets/brand/profile_800.png` (오래 박사 아이콘) |
| 배너 | `assets/brand/banner_2560x1440.png` |
| 워터마크 | `assets/brand/watermark_150.png` |
| 로고 | `assets/brand/logo_lockup.png` (밝은 배경), `logo_lockup_dark.png` (어두운 배경) |

**이름 뜻:** '인생 후반전'을 맞은 40~60대가 몸과 돈을 함께 챙기는 잡학. '건강'을 이름에 넣지 않아서 경제 편을 올려도 어색하지 않습니다.

**중복 확인 (2026-10-16, YouTube 채널 검색):**
- '후반전 잡학', '후반전잡학'과 같은 이름의 채널은 없었습니다.
- '후반전'만 쓰는 4060 채널은 많습니다(원더풀 인생후반전 54만, 인생 후반전 1.6만, 유쾌한 후반전 1.54만, 5060 후반전, 건강한 후반전 등). 그래서 **항상 '후반전 잡학'을 붙여서** 쓰고, 아이콘과 썸네일에 오래 박사를 꾸준히 넣어 구별합니다.
- 핸들을 쓸 수 있는지는 여기서 확인할 수 없습니다. 유튜브 스튜디오의 맞춤설정 → 기본 정보 → 핸들에 입력하면 바로 알려 줍니다.

## 2. 한 줄 소개 (배너·프로필)
- **기본:** 인생 후반전, 몸과 돈을 함께 챙기는 잡학
- 다른 안: 40대부터 알아 두면 좋은 건강과 돈 이야기

## 3. 채널 설명 (유튜브 '설명' 칸에 붙여 넣기)
```
인생 후반전, 몸과 돈을 함께 챙기는 잡학 채널입니다.

매일 먹는 음식이 몸에서 어떤 변화를 만드는지, 연금·건강보험료·노후 자금처럼 40~60대가 알아 두면 좋은 돈 이야기까지
연구 결과와 공식 자료를 근거로 쉽게 정리해 드립니다.

■ 안내
- 이 채널의 영상은 일반 정보이며 진단·치료나 투자 권유를 대신하지 않습니다.
- 개별 건강 상담과 투자 상담은 받지 않습니다.
- 내레이션은 AI 음성으로 제작하며, 대본은 직접 작성하고 검수합니다.
- 오래 박사와 등장인물은 그림 캐릭터이며 실존 인물이나 의료·금융 전문가가 아닙니다.
```

안내 문구를 넣는 이유는 `07_규정체크리스트.md`에 있습니다: 합성 콘텐츠 표시, 전문가 사칭 금지, 유사투자자문(양방향 상담) 금지.

## 4. 채널 키워드 (스튜디오 → 설정 → 채널 → 기본 정보 → 키워드, 쉼표로 구분)
```
건강정보, 건강잡학, 잡학상식, 중년건강, 40대 건강, 50대 건강, 60대 건강, 음식 효능, 몸이 보내는 신호, 갱년기, 노후준비, 국민연금, 건강보험료, 피부양자, 연금저축 IRP, 두뇌 퀴즈, 초성 퀴즈, 후반전 잡학
```
- 채널 키워드는 한 번만 넣습니다. **영상마다 넣는 '태그'와는 다릅니다.**
- 영상 태그는 그 영상 주제어 7~12개 + 공통 3개(건강정보, 중년 건강, 후반전 잡학)로 씁니다. 예시는 `episodes/001_커피/05_업로드정보.md`의 태그 칸. 영상과 상관없는 태그를 많이 넣으면 유튜브 스팸 정책(오해를 부르는 메타데이터)에 걸릴 수 있습니다.

## 5. 영상 제목에 채널명 넣기
`03_포맷공식.md`의 기본형처럼 제목 끝 부제 자리에 넣습니다.
- 예: `매일 커피 마시는 사람, 몸에서 ○○가 바뀝니다 | 믹스커피는 괜찮을까? 후반전 잡학 간/혈당/심장`
- 제목이 100자를 넘으면 키워드부터 줄이고, 채널명은 빼도 됩니다.

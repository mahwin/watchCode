## A2. 반드시 지킬 원칙
1. **근거 없이 숫자를 쓰지 않는다.** 모든 수치에 출처. 원문을 직접 확인했으면 ✅, 보도·2차 자료면 ⚠️.
2. **단정하지 않는다.** 관찰 연구는 "~와 관련이 있었다", "~경향이 있었다". "낫는다·완치·치료된다·거의 모두"는 금지.
3. **전문가를 사칭하지 않는다.** 오래 박사는 별명. 흰 가운, 청진기, 자격 표기, "의사로서" 같은 말 금지.
4. **대본은 새로 쓴다.** 다른 영상이나 레퍼런스 문장을 베끼지 않는다.
5. **한국 자료를 우선한다.** 대한간학회, 질병관리청 국가건강정보포털, 국민건강보험공단, 국민건강영양조사 연구 등. 최소 2개.
6. **실존 브랜드 로고·제품명은 쓰지 않는다.** 일반 포장 그림으로 대신한다.
7. 증상이 나오는 편이므로 **"증상이 있으면 의료기관에서 진료를 받으세요"**를 넣는다.

## A7. 내레이션 규칙
**말투**
- 본문은 다큐체(~다, ~이다). 「생로병사의 비밀」 같은 차분하고 권위 있는 톤
- 질문형 전환: "~일까?", "~살펴보자"
- **마지막 인사만 존댓말**: "구독과 좋아요 부탁드립니다."
- 문장은 짧게, 한 문장에 정보 하나. 귀로만 들어도 이해되게
- 겁주지 않는다. "~면 위험합니다" 대신 "~라면 한 번 확인해 볼 때다"

**훅 5단계 (60초 안팎):** ①상황 맞히기 → ②상식 뒤집기 → ③규모·최신성 → ④주의 → ⑤목차 + 열린 고리

**항목 공식 (체크·습관 항목마다 40~60초):** ①번호와 제목("두 번째, 오른쪽 윗배.") → ②배경 한두 문장 → ③연구(연도, 규모) → ④숫자(관찰 연구는 '경향', '관련') → ⑤이유 한 문장 → ⑥반전이나 한국 자료 → (선택) 다음 구간 예고

**전환 문장 예시 (그대로 쓰지 말고 이번 편에 맞게 바꿈)**
- 다시 붙잡기: "여기까지 들으면 '나는 술을 안 마시니까 괜찮다'고 생각할지도 모른다. 하지만…"
- 마지막 공개: "그런데 처음에 말한 가장 중요한 포인트가 하나 남았다."
- 앞 내용 불러오기: "앞에서 본 '허리둘레'를 기억하자."
- 주의: "잠깐, 여기서 많이들 실수한다."

**마무리 공식:** ①한 문장 정리 → ②3줄 요약("오늘 내용을 정리하면 세 가지다.") → ③댓글 질문 → ④구독 요청(존댓말, 한 번) → ⑤**시그니처: "오늘 배운 잡학으로, 오래오래 건강하게. 오래 박사였습니다."**

## A8. 화면 규칙
- 내레이션 1~2문장 = 1컷, 컷당 4~8초. 같은 그림을 10초 넘게 두지 않는다 (같은 그림을 확대 위치만 바꿔 2~4컷에 나눠 써도 됨)
- 숫자가 나오는 문장은 **숫자 카드**(큰 숫자 하나 + 아래 설명 한 줄)
- 항목 시작마다 **번호 카드**(흰 배경, 큰 번호 + 제목, 오래 박사 작은 포즈) 1~2초
- 연구를 말할 때 화면 왼쪽 아래에 작은 회색 **출처 자막** ("기관·저자, 저널 연도")
- 바로 병원 신호 구간은 **빨간 경고 테두리** + 오래 박사 경고 얼굴
- 움직임: 정지 그림에 천천히 확대(100→105~110%), 숫자·아이콘은 톡 튀어나오게, 전환은 컷이나 짧은 디졸브
- 자막: 화면 아래 최대 2줄, 굵은 고딕, 흰 글씨 + 검은 테두리. 핵심 단어 하나만 노랑·빨강
- 대본에는 구간마다 `> **화면:**` 줄로 순서대로 적는다. 예: `> **화면:** 번호 카드 '2. 오른쪽 윗배' → 주인공이 배에 손을 얹는 컷 → 간 위치 표시 / 출처: ○○학회 지침 2025`

```
첨부한 마크다운 파일은 유튜브 채널 '후반전 잡학'의 004편 제작서다. 이 파일 하나만 보고 작업한다.
1) PART A(특히 A2 원칙)와 PART B의 공통 규칙을 읽어라.
2) 너는 PART B의 [R번호]만 맡는다. 대본은 쓰지 않는다.
3) 웹 검색으로 근거를 찾고, 출처 우선순위를 따른다. 원문을 직접 열어 확인한 것만 ✅, 보도나 2차 자료는 ⚠️로 표시한다.
4) [R번호]의 '✏️ 여기에 작성' 자리에 들어갈 내용(결과 표 + 대본 담당에게 주는 메모)만 마크다운으로 돌려줘라.
```

**대본 담당 (PART C가 채워진 뒤)**
```
첨부한 마크다운 파일은 유튜브 채널 '후반전 잡학'의 004편 제작서다. 이 파일 하나만 보고 작업한다.
1) PART A 전체, PART B 조사 결과, PART C 총괄 확정을 읽어라.
2) A6 비트 순서와 A7 말투, A8 화면 규칙을 지켜 PART D(D1 구성표, D2 제작 대본, D3 TTS 원고)와 PART F(업로드 정보)를 채워라.
3) 사실은 PART B·C에 있는 것만 쓴다. 길이는 14~16분(공백 뺀 글자 수 약 3,500~4,000자).
4) 채운 PART D와 PART F를 마크다운으로 돌려줘라.
```

**이미지 담당 (PART D가 채워진 뒤)**

```
첨부한 마크다운 파일은 유튜브 채널 '후반전 잡학'의 004편 제작서다. 이 파일 하나만 보고 작업한다.

3) 모든 프롬프트에 글자 금지, 로고 금지, 차분한 색 문장을 넣는다.
4) 채운 PART E를 마크다운으로 돌려줘라.
```

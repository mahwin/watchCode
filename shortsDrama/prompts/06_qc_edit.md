# 06. 검수 · 편집 · 렌더링 가이드

## 6-1. 이미지 검수 (영상 생성 전에 반드시)
영상 생성은 비싸니까 **이미지 단계에서 걸러야** 해요.

| 항목 | 불합격 기준 |
|---|---|
| 얼굴 일관성 | 캐릭터 시트와 다른 사람처럼 보임 |
| 의상 일관성 | 진주가 사라짐, 작업복 색이 바뀜 |
| 손·손가락 | 6개, 녹아내림, 물건과 합쳐짐 |
| 글자 | 이미지 안에 깨진 글자나 간판 (명찰 클로즈업은 편집에서 글자를 합성) |
| 장소 일관성 | 같은 룸인데 벽지나 조명이 다름 |
| 감정 | 대사 감정과 표정이 다름 (화내야 하는데 웃음) |

## 6-2. 영상 검수 (MODE A)
| 항목 | 불합격 기준 |
|---|---|
| 립싱크 | 입 모양과 대사가 0.3초 이상 어긋남 |
| 한국어 발음 | 단어가 뭉개지거나 외국어 억양 |
| 화자 혼동 | 다른 인물이 대사를 말함 |
| 모핑 | 얼굴이나 손이 중간에 변형됨 |
| 불필요한 음악·자막 | 모델이 음악이나 자막을 넣음 |

→ 불합격 컷은 프롬프트를 고쳐서 다시 생성해요. 같은 컷을 3번 실패하면 컷을 둘로 쪼개거나 MODE B(이미지 + TTS)로 대체해요.

## 6-3. 편집 규칙 (CapCut / Vrew / Premiere)
- **자막:** 레퍼런스 40편의 원본 프레임(1080×1920)을 측정한 기준이에요.
  - **위치:** 가로 가운데 정렬, 세로는 텍스트 블록의 중심이 위에서 **약 1,150~1,300px (60~68%)** 지점. 인물의 턱과 가슴 사이예요.
  - **크기:** 레퍼런스 글자 높이는 약 55~60px(화면 높이의 3%)로 작은 편이에요. **우리는 70~80px로 키워요** (시니어 시청층 고려).
  - **스타일:** 흰 글씨, 검은 외곽선 3~4px, 박스나 배경 없음. 둥근 고딕 또는 손글씨체.
  - **양:** 한 줄 최대 약 17자, 넘으면 2줄 (최대 2줄). 대사 한 마디마다 화면을 바꿔요.
  - **화자 표시:** 없음 (이름 표시, 색 구분 없음).
- **채널 워터마크:** 오른쪽 위 구석에 채널명을 두 줄로, 흐린 손글씨체(높이 약 50px)로 넣어요. 재업로드 방지용으로 "채널명" 반투명 텍스트를 장면 중간에 가끔 띄우기도 해요.
- **엔딩 자막:** 마지막 장면에 "재밌게 보셨다면 / 구독과 좋아요 / 부탁드립니다." 3줄을 화면 가운데(약 47~65% 지점)에 대사 자막보다 큰 글씨(약 90px)로 넣고, 흰색 글로우와 반짝이 별 스티커를 붙여요.
- **워터마크:** 채널명은 우측 상단. 생성 툴 워터마크가 있으면 그쪽을 피해서 배치
- **효과음:** 반전 순간에 "헉", 물건 떨어질 때 "툭", 해소 장면에 "박수"
- **음악:** 레퍼런스 3편을 음원 분리해서 측정한 기준이에요.
  - **처음부터 끝까지 깔아요.** 드럼과 비트는 없이, 피아노와 현악기 중심의 잔잔한 배경음악이에요.
  - **볼륨:** 대사가 나올 때 음악은 대사보다 **약 9~11dB 작게**, 대사가 쉬는 구간에서는 **3~6dB 올려요** (자동 더킹).
  - **조성:** 갈등·긴장 이야기는 단조(예: G minor), 따뜻한 감동 이야기는 장조(D·E major).
  - **흐름:** 대사 없는 감정 구간(5~10초)에서는 음악을 크게 올리고, 엔딩으로 갈수록 점점 키우는 방식도 써요.
- **컷 전환:** 하드컷만 사용 (디졸브나 화려한 전환은 금지). 음악은 끊지 않고, 반전·클라이맥스 대사 동안에만 음악을 3~6dB 더 낮춰요
- **MODE B 모션:** 컷마다 줌 5~8%, 반전 컷만 흔들림 효과
- **엔딩:** 마지막 2초에 댓글 유도 질문 자막

## 6-4. 최종 렌더링
- 1080x1920, 30fps, H.264, 오디오 AAC 48kHz
- 길이 110~125초
- 파일명: `ep{번호}_{제목 요약}.mp4`

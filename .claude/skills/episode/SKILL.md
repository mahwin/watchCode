# 새 에피소드 만들기

> 경로는 모두 **키트 폴더** 기준입니다. 저장소 전체를 열었다면 `orae-channel/`, 키트 폴더를 바로 열었다면 현재 폴더가 키트 폴더입니다. 도구 출력 파일(JSON)이 키트에 쌓이지 않도록 도구는 임시 폴더에서 실행하고 키트 경로를 붙여 부릅니다.

입력: 주제 (예: `계란`, `국민연금 수령 시기`). 없으면 `docs/08_주제백로그.md`의 다음 '대기' 주제를 제안하고 확인받는다.

## 0. 준비 (반드시)
`CLAUDE.md`와 아래 문서를 읽는다.
- `docs/03_포맷공식.md`, `docs/04_내레이션가이드.md`, `docs/05_화면구성가이드.md`, `docs/06_캐릭터바이블.md`, `docs/07_규정체크리스트.md`, `docs/09_장면이미지라이브러리.md`
- 완성 예시 `episodes/001_커피/` 전체. **형식은 따르되 문장은 베끼지 않는다.**

## 1. 폴더 만들기
`episodes/`의 마지막 번호 + 1로 `NNN_주제/` 폴더를 만든다. 양식은 `templates/에피소드_패키지.md`.

## 2. 00_기획.md
- 주제 검증: 03 문서의 체크리스트 5개 항목 점수. 4번(수요)은 `python3 <키트>/tools/demand_scan.py <주제>`를 **스크래치 폴더에서** 실행해 실제 수치로 채운다. 4점 미만이면 멈추고 사용자에게 대안 주제 2~3개를 제안한다.
- 타깃(남/여/공통), 주인공 선택
- 제목 후보 3개 (03의 형식 중 서로 다른 형식으로)
- 썸네일 1줄·2줄 문구와 장면 구성
- 끝까지 보게 할 장치 3개 이상 (열린 고리 2개 포함)

## 3. 01_리서치.md
- 웹 검색으로 연구와 수치를 모은다. **한국 자료를 최소 2개** 넣는다(국민건강영양조사 연구, 식약처, 질병관리청, 한국소비자원 등).
- 표: 주장 / 수치 / 연구 설계(관찰·실험·메타분석) / 출처(저자·저널·연도·링크) / 확인 상태(✅ 직접 확인, ⚠️ 보도·2차 자료)
- 서로 엇갈리는 연구는 엇갈린다고 그대로 적는다.
- 위험 신호(약물 상호작용, 특정 질환자 주의)를 따로 정리한다.

## 4. 02_제작대본.md + 03_TTS원고.txt
- 03 문서의 구성 템플릿(훅 → 기초 → 제목 답 공개 + 효과 → 다시 붙잡기 + 하면 안 되는 습관 → 고르는 법 → 함께 먹을 것 → 마지막 공개 → 마무리)을 따른다. 경제 주제는 '효과' 대신 '제도와 계산', '하면 안 되는 습관' 대신 '흔한 실수'로 바꾼다.
- 04 문서의 훅 공식, 항목 공식, 전환 문장, 금지 표현을 지킨다. 다큐체, 마지막 인사만 존댓말, 시그니처 멘트로 끝낸다.
- 구간마다 `> **화면:**` 지시를 05 문서 방식으로 쓰고, 연구가 나오는 구간에는 출처 자막을 적는다.
- 03_TTS원고.txt에는 내레이션만, 구간 사이를 빈 줄로 나눈다.
- `python3 <키트>/tools/duration.py <03_TTS원고.txt>`로 길이를 재서 **14~17분**에 맞춘다. 결과를 02 문서 상단에 적는다.

## 5. 04_이미지프롬프트.md
- 썸네일: 06 문서의 '썸네일 장면 틀'을 채운다. 남녀 2안이 필요하면 둘 다.
- 장면 목록은 `docs/09_장면이미지라이브러리.md`의 구간별 목록을 기준으로 25~40장을 고르고, 한국식 배경 문장을 넣는다. 글자·숫자·그래프는 그림에 넣지 않고 편집용 메모로 적는다.
- 영상 장면: 새로 그려야 하는 장면(보통 10~20개)을 장면 번호와 함께 '영상 장면 틀'로 쓴다. 이미 있는 표정·포즈 PNG로 되는 장면은 "기존 에셋: 오래 박사_경고"처럼 적는다.
- 모든 프롬프트에 브랜드 로고 금지, 글자 금지 문장을 넣는다.

## 6. 05_업로드정보.md
제목(최종 1개 + A/B 후보 2개), 설명란(두 줄 요약, 챕터 시간, 참고 자료, 안내 문구: 면책·AI 음성·제휴), 해시태그 3개, 고정 댓글 질문.

## 7. 06_검수.md
`/episode-review` 스킬과 같은 기준으로 07 문서의 체크리스트를 채우고, 남은 확인 사항(⚠️ 자료의 원문 확인 등)을 목록으로 남긴다.

## 8. 마무리
- `docs/08_주제백로그.md`의 해당 주제 상태를 갱신한다.
- 사용자에게 한국어로 짧게 보고한다: 제목, 길이, 끝까지 보게 할 장치, 사용자가 직접 할 일(이미지 생성, TTS, ⚠️ 자료 원문 확인).

# EP012 「거래처」 (담백한 사이다 + 2차 반전)

**제목:** 10년 만의 동창 모임, 남편 자랑하던 친구들… 계산 끝낸 친구에게 본부장 남편이 고개를 숙였다 #시니어드라마 #시니어쇼츠 #시니어 #반전드라마
**로그라인:** 10년 만의 여고 동창 모임. 친구들은 남편 승진과 병원 개원을 자랑하며, 일하다 늦게 온 춘희를 "이 나이에 고생한다"고 은근히 무시한다. 밥값 앞에서 다들 핑계를 대자 춘희는 이미 계산을 끝냈다고 말한다. 그때 친구 남편인 본부장이 식당에 들어와, 춘희에게 먼저 허리를 숙인다.
**참고:** 사연콸콸 "10년만의 여고동창모임"(64만)의 구조(자랑 → 은근한 무시 → 밥값 → 미리 계산)를 따르되, 인물·대사는 새로 쓰고 2차 반전을 더했어요.
**반전:** ① 춘희가 이미 계산함, 식당은 춘희의 거래처 ② 친구 남편(본부장)의 회사가 춘희 회사의 거래처, 남편이 춘희에게 "대표님" 하고 인사
**길이:** 약 1분 45초

## 등장인물
| id | 이름 | 설명 |
|---|---|---|
| C1 | 춘희 (61) | 식자재 유통 회사 대표. 수수한 점퍼 차림 |
| C2 | 선영 (61) | 남편이 식품회사 본부장으로 승진. 제일 말이 많음 |
| C3 | 은주 (61) | 남편이 병원 2호점 개원 |
| C4 | 선영 남편 (60대) | 식품회사 본부장 |

## 나레이션

```
[0초 / 고급 한정식집 룸. 동창 둘이 수다를 떤다]
은주: 선영아, 너희 남편 이번에 본부장 됐다며? 축하해!
선영: 축하는 뭘. 너희 남편은 병원 2호점 냈다며? 그게 더 대단하지.
은주: 아유, 우리 남편은 바빠서 얼굴도 못 봐. 돈 버는 기계야, 기계.
선영: 근데 춘희는 왜 안 와? 10년 만인데 첫날부터 늦네.

[16초 / 춘희 등장]
춘희: (점퍼 차림으로 급히 들어오며) 미안, 미안! 납품 하나 마치고 오느라.
선영: 얘는 학교 다닐 때도 맨날 지각하더니 여전하네.
은주: 납품? 너 아직도 일해?

[26초 / 은근한 무시]
춘희: 응, 식당에 식자재 대는 일 해. 벌써 15년 됐네.
선영: 어머, 남편이 벌어다 주는 거 쓰면 될 걸. 이 나이에 새벽부터 고생이다.
은주: (춘희 점퍼를 슬쩍 보며) 그래도 오늘 같은 날은 좀 꾸미고 오지. 여기 비싼 데야.
선영: 너 오늘 부담되면 말해. 우리가 이해할게.
춘희: (웃으며) 부담은 무슨. 많이들 먹어.

[44초 / 계산 시간]
선영: 자, 다 먹었으면 커피 마시러 가자. 근데… 밥값이 꽤 나왔겠다?
은주: 선영이 너희 남편 승진 턱으로 네가 내면 되겠네.
선영: 나도 그러고 싶은데, 본부장이라도 월급쟁이잖아. 은주 너야말로 병원 개원 턱 내야지.
은주: 개원하느라 대출이 얼마인 줄 알아? 요즘 우리 집 허리띠 졸라매.
선영: 그럼 그냥 셋이 나눠서…

[60초 / 반전 ①]
춘희: 됐어. 아까 들어오면서 계산했어.
선영: 네가? 여기 코스가 얼만데?
춘희: 여기 내 거래처야. 내가 대는 고기랑 나물로 밥 먹은 건데, 내가 내야지.
춘희: 그리고 너희는 남편 돈이잖아. 남의 돈으로 비싼 밥 사면 눈치 보여. 커피만 사.
[선영과 은주가 서로 얼굴을 본다]

[74초 / 반전 ②]
[룸 문이 열리고 정장 차림의 선영 남편이 들어온다]
선영: (반가워하며) 어머, 여보! 데리러 왔어? 다들, 우리 남편이야. 본부장.
선영 남편: (선영을 지나쳐 춘희 앞에 서더니 허리를 깊이 숙인다) 대표님! 여기 계셨습니까.
선영 남편: 이번 납품 계약 덕분에 제가 본부장 단 겁니다. 정말 감사합니다.
선영: (얼어붙는다) …대, 대표님?  [헉]
춘희: (손을 내저으며) 아유, 본부장님이 일을 잘하셔서 그렇지. 앉으세요, 커피는 선영이가 산대요.

[90초 / 해소]
선영: (얼굴이 빨개지며) 춘희야… 너 그렇게 큰 회사였어? 왜 말 안 했어?
춘희: 자랑할 게 뭐 있어. 새벽에 일어나서 열심히 산 거지.
춘희: 너희가 남편 자랑할 때, 난 그냥 내가 자랑스러웠어.
은주: (웃음을 터뜨리며) 야, 오늘 커피는 진짜 비싼 걸로 사야겠다.
[넷이 웃으며 룸을 나선다 → 정지 화면]

[105초 / 엔딩 자막]
"여러분 모임에도 말없이 먼저 계산하는 친구가 있나요?"
```

## 작가 노트
- **원본 구조는 그대로:** 자랑 → 늦게 온 친구 → 은근한 무시 → 밥값 떠넘기기 → 미리 계산. 짧고 단순해서 제작비가 적게 들어요(장소 1곳, 인물 4명).
- **2차 반전:** 남편 자랑의 주인공인 본부장이 직접 들어와, 무시당하던 춘희에게 먼저 허리를 숙여요. 선영이 자랑하던 "남편 승진"이 바로 춘희 덕분이었다는 게 드러나요. 원본은 한마디로 끝났지만, 이 버전은 **눈으로 보이는 반전**이 하나 더 있어요.
- **선영이 남편을 소개하는 순간이 최고점이에요.** "다들, 우리 남편이야. 본부장." 바로 다음에 남편이 춘희에게 "대표님!" 하고 인사하니, 자랑이 그대로 되돌아와요.
- **감정 한 줄:** "너희가 남편 자랑할 때, 난 그냥 내가 자랑스러웠어." 원본의 낮은 좋아요율(약 0.6%)을 보완하는 명대사예요.
- **저작권 메모:** 원본의 구조와 무대는 참고했지만, 대사는 전부 새로 썼어요. 원본 대사를 그대로 쓰지 마세요.
- **배경음악:** 0~44초 가볍고 경쾌한 곡, 44초 계산 장면부터 살짝 긴장감, 74초 남편 등장에 "헉" 효과음, 90초부터 따뜻한 피아노.
